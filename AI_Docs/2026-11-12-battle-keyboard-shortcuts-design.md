# 배틀 키보드 단축키 변경 설계

## 의도

배틀 행동 단축키를 이동 `F`, 방향 전환 `D`, 연성제 `C`, Undo `Z`, Redo `X`로 통일한다. 스킬 `Q/W/E/R`과 타임라인 슬롯 숫자키는 유지한다.

## 조사 결과

- 이동·전환·연성제는 `BattleCharacterPanelUI`에서 각각 `A/S/D`로 처리한다.
- 일반 전투, 첫 전투 입력 제한, 튜토리얼 분기에 키가 각각 중복 작성되어 있다.
- `BattleTimelineController`에 `Q` Undo 메서드가 있지만 `Update`에서 호출하지 않아 실제 단축키로 동작하지 않는다.
- Redo는 버튼과 Alt+우클릭만 있고 키보드 입력은 없다.
- 타임라인 슬롯 좌우 이동용 `A/D` 메서드는 현재 호출되지 않지만 새 `D` 전환과 의미가 충돌한다.

## 선택한 접근

- `BattleKeyboardShortcutBindings`를 키 매핑의 단일 소스로 추가한다.
- 행동 UI는 기존 버튼 메서드를 호출하여 UI가 전투 상태를 직접 변경하지 않게 한다.
- Undo/Redo 입력은 `BattleTimelineController`가 소유하고 기존 공개 API를 호출한다.
- 슬롯 좌우 이동 키는 향후 활성화되어도 충돌하지 않도록 좌우 방향키로 변경한다.

## 범위와 제약

- 스킬 `Q/W/E/R`, 슬롯 `1~5`, 실행 `Space`, 메뉴 `Escape`는 변경하지 않는다.
- 메뉴, 텍스트 입력, 튜토리얼 제한, 행동 실행 중 입력 차단 규칙을 유지한다.
- 전투 명령·상태·랜덤·네트워크 프로토콜은 변경하지 않는다.

## 완료 조건

- `F/D/C/Z/X`가 각각 이동·전환·연성제·Undo·Redo를 실행한다.
- 기존 `A/S` 행동 단축키와 연성제 `D`는 더 이상 실행되지 않는다.
- `Q/W/E/R` 스킬 단축키는 유지된다.
- Undo/Redo는 캐릭터 선택 여부와 관계없이 예약 입력 가능 상태에서 동작한다.
