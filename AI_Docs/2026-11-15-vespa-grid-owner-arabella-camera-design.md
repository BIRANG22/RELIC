# 베스파 방향·그리드 효과 소유자·아라벨라 카메라 복구 설계

## 목표

- 베스파가 이동 후 빈 방향으로 플립 공격하지 않도록 실행 직전 실제 유효 대상을 기준으로 방향을 보정한다.
- 거미알을 몬스터로 바꾸지 않고 생성자 ID를 가진 그리드 효과로 유지하며 생성자 자신의 피해를 차단한다.
- 아라벨라 등장 줌인 후 원래 카메라로 줌아웃하고, 전투 입력 활성화 뒤 선택 캐릭터 포커스로 이어지는 순서를 복구한다.

## 설계

### 베스파

예약 방향에 실행 시점의 유효 대상이 남아 있으면 유지한다. 예약 방향이 비고 반대 방향에만 대상이 있으면 반대로 전환한 뒤 실제 위치 기준 범위를 재계산한다. 양쪽이 모두 비면 예약 결정을 유지한다.

### 거미알

`BattleGridEffectPlacement`와 상태에 `OwnerRuntimeId`, `OwnerMonsterId`를 저장한다. 배치, 만료, 저장·복원에서 소유자를 보존하고 공격자의 RuntimeId가 소유자와 같으면 피해를 거부한다. 다른 몬스터와 플레이어의 기존 피해는 유지한다.

### 아라벨라 카메라

프리팹의 종료 복귀 옵션을 다시 켠다. `BossSpawnPresentation`의 기존 블렌드 복귀가 끝난 뒤 인트로가 종료되고, `BattleRoomLoader`가 입력을 활성화한 다음 현재 선택 캐릭터에 `FocusOnCharacterSelection()`을 적용하는 기존 흐름을 사용한다.

## 비범위

- 거미알의 몬스터/타임라인 유닛 전환
- 모든 몬스터 AI의 실행 시점 재타기팅
- 카메라 파라미터나 아라벨라 등장 애니메이션 변경

## 멀티플레이 경계

방향 결정과 그리드 효과 소유자는 안정적인 RuntimeId/MonsterId 기반 상태로 둔다. UI·VFX는 결과를 계산하지 않는다. 현재 별도 그리드 효과 네트워크 메시지는 없으며 저장 스냅샷에는 소유자 ID를 포함한다.
