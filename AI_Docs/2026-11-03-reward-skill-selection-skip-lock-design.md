# 기억 선택 연출 중 넘어가기 버튼 잠금 설계

## 의도

기억 보상 화면에서 스킬 카드를 선택한 순간부터 선택·장착 연출이 끝날 때까지 `SkipButton`의 클릭, 호버 연출, 상호작용 사운드를 모두 차단한다.

## 목표

- 빈 스킬 슬롯에 즉시 장착되는 선택과 기존 스킬 교체 단계로 진입하는 선택 모두에서 버튼을 즉시 잠근다.
- 기존 `SetSkipRevealState(false)` 경로를 재사용해 `Button.interactable`, 색상, `DBAudioSource` 상호작용, `UIChildHoverTransform` 이동 연출을 한 번에 갱신한다.
- 선택 연출과 장착 결과에는 영향을 주지 않는다.

## 비목표

- 스킬 카드와 장착 슬롯의 선택 흐름은 변경하지 않는다.
- 넘어가기 버튼의 활성 색상, 비활성 색상 또는 배치·씬 데이터를 변경하지 않는다.
- 다른 보상 패널의 넘어가기 버튼 동작은 변경하지 않는다.

## 접근

### 선택한 접근

`BattleRewardSkillPanelUI`에 선택 시작 전용 잠금 메서드를 두고, 교체 선택 진입과 최종 선택 확정 두 경로에서 호출한다. `SetSkipRevealState(false)`가 버튼, 색상, 오디오와 함께 `UIChildHoverTransform`을 기본 위치로 복구한 뒤 비활성화하도록 한다. 또한 `processing`, 선택 카드, 교체 대기 상태를 공통 잠금 조건으로 사용해 다른 카드의 늦은 Reveal 완료가 버튼을 다시 활성화하지 못하게 한다.

### 검토한 대안

- `DiscardReward()` 조건만 강화: 실제 보상 건너뛰기는 막지만 호버·클릭 연출은 남으므로 제외한다.
- 씬에 별도 입력 차단 오브젝트 추가: 기존 Button/애니메이션 잠금 기능과 중복되고 씬 변경이 불필요해 제외한다.

## 멀티플레이 경계

보상 UI의 로컬 상호작용 잠금만 변경한다. 스킬 장착 데이터와 보상 완료 결과 계산에는 영향을 주지 않는다.
