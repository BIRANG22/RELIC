# 연성 레시피 물음표 글리프 회귀 수정 설계

## 의도

`CompoundRecipeSlot/Background/Value`가 미발견 레시피의 `???`를 `ㅂ` 모양으로 표시하는 회귀를 제거하고, 같은 문제가 폰트 재생성 과정에서 다시 들어오지 않도록 한다.

## 원인

- `Value`는 `DungGeunMo Legacy SDF`를 사용하고 `CompoundRecipeSlotUI`는 미발견 레시피에 U+003F(`?`)를 직접 출력한다.
- `e449269ec`에서 Legacy 폰트 에셋이 갱신되며 잘못된 직접 `?` 문자(글리프 인덱스 15138)가 다시 추가되었다.
- 같은 변경에서 정상 `?`를 공급하던 fallback 폰트 연결도 제거되었다.
- 기존 회귀 테스트는 올바른 상태를 요구하지만 `Value`가 해당 Legacy 폰트를 사용한다는 연결 관계는 검증하지 않는다.

## 선택한 접근

Legacy 폰트에서 직접 `?` 문자 매핑과 해당 전용 글리프를 제거하고 기존 정상 fallback 폰트를 복원한다. 아울러 프리팹의 `Value`가 회귀 방지 대상 폰트를 계속 사용하며 `?`를 fallback으로 해결하는지 검사한다.

대안으로 `Value`만 다른 폰트로 교체하거나 `???`를 이미지로 바꾸는 방법이 있으나, 발견된 레시피 이름까지 같은 텍스트가 담당하므로 로컬라이징과 레이아웃 영향이 커서 제외한다.

## 범위

- Legacy TMP 폰트 에셋의 잘못된 직접 문자/글리프 및 fallback 구성 수정
- `CompoundRecipeSlot`의 실제 `Value` 연결을 포함한 EditMode 회귀 테스트 보강
- C# 컴파일 및 가능한 EditMode 검증

## 비범위

- 미발견 레시피 표기 방식 변경
- 다른 UI 또는 폰트 체계 전면 개편
- Unity 에디터 화면 직접 확인

## 멀티플레이 경계

표시용 TMP 폰트와 에디터 테스트만 변경하며 전투 상태, 명령, 결과 이벤트 및 랜덤 처리에는 영향이 없다.
