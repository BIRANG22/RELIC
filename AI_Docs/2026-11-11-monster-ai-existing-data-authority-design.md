# 몬스터 AI 기존 데이터 권위화 설계

## 목적

몬스터 AI의 행동 정책은 유지하면서, 이미 `MonsterSkillData`, `MonsterMasterData`, `RangeDatabase`에 존재하는 값을 코드 상수나 좌표 배열이 덮어쓰지 않게 한다.

## 범위

- 전체 몬스터 AI와 몬스터 예약·실행 경로를 검사한다.
- 이동 후보의 원본은 이동 스킬의 `RangeId`와 `SkillRangeData.Positions`로 생성한다.
- AI는 “정확히 2칸 도망”, “가장 가까운 대상 접근” 같은 정책 필터와 점수 계산만 담당한다.
- 공격 범위 문자열과 데이터에 이미 존재하는 거리 수치는 해당 `MonsterSkillData`에서 읽는다.
- 몬스터·스킬을 식별하여 전용 동작을 선택하는 ID 분기와 행동 순서·확률·횟수는 유지한다.
- 새 CSV 필드나 새 게임 데이터는 만들지 않는다.

## 설계

`MonsterSkillRangeService`에 스킬 데이터의 범위 좌표를 이동 오프셋으로 반환하는 API를 추가한다. 이 API는 보드 위치와 무관한 원본 오프셋을 제공하고, 좌우 비대칭 범위는 현재 방향에 맞춰 반전한다. 각 AI는 기존 정적 이동 배열 대신 이 API의 결과를 순회한다.

공격 판정에서 직접 작성된 범위 ID는 해당 스킬의 `RangeId`로 교체한다. 데이터에 숫자 필드가 존재하는 특수 이동 거리는 그 필드에서 읽고, 데이터에 대응 값이 없는 정책 상수는 유지한다.

## 실패 처리

스킬 또는 범위 데이터가 없으면 임의의 하드코딩 범위로 대체하지 않고 빈 후보를 반환한다. 잘못된 데이터가 실제 전투에서 조용히 다른 행동으로 변하는 것을 방지한다.

## 검증

- 사용자 정의 테스트 범위로 이동 오프셋을 만들었을 때 데이터 좌표와 정확히 일치하는지 검증한다.
- 방향 반전과 누락 데이터 처리를 검증한다.
- 전체 AI 소스에 기존 이동 좌표 배열 및 직접 범위 문자열이 남지 않았는지 회귀 검사한다.
- EditMode 테스트와 C# 프로젝트 컴파일을 수행한다.
