# 준비 번역문 교체 구현 계획

1. 제공 번역 목록을 검증 데이터로 정리한다.
2. 엑셀과 Unity String Table asset을 검사하는 EditMode 테스트를 추가한다.
3. 테스트와 같은 매핑을 사용하는 일괄 갱신 스크립트로 엑셀 `Text` 시트 값을 교체한다.
4. 엑셀에서 찾은 Key들을 기준으로 `Text_en`, `Text_zh-Hans`, `Text_ja`, `Text_es` 값을 갱신한다.
5. 정적 검증으로 모든 제공 원문이 발견되고 번역값이 일치하는지 확인한다.
6. `RELIC.sln` 빌드로 테스트 코드 컴파일과 프로젝트 컴파일을 확인한다.
