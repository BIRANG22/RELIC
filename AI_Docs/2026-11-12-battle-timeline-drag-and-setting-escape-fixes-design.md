# 배틀 타임라인 드래그 및 설정 ESC 수정 설계

## 의도

예약 행동을 클릭으로 제거해도 복구할 수 있게 하고, 타임라인 드래그 중 행동 점유 칸을 실제 배치 전에 확인할 수 있게 한다. 자원이 부족한 신규 행동은 드래그 자체를 시작하지 않으며, 설정 패널이 열린 상태의 ESC는 메뉴를 열지 않고 설정 패널만 닫는다.

## 조사 결과

- 클릭 삭제는 `RemoveCommandFromNetwork`에서 해당 명령의 Undo 기록과 전체 Redo 기록을 제거하므로 `RedoLastPlayerReservation`이 복구할 대상이 사라진다.
- 드래그는 `TimelineReservationDragContext`의 포인터 아이콘만 갱신하고 삽입 위치는 드롭 순간에만 계산한다. 임시 점유 칸이나 재배치 프리뷰 상태가 없다.
- `TryBeginTimelineSkillDrag`은 클릭 경로에서 사용하는 `CanUseSkillWithPreviewResource` 검사를 호출하지 않는다.
- `BattleSettingPanelUI`는 ESC를 처리하지 않고, `BattleMenuEscapeInputController`는 설정 패널을 모른 채 닫힌 MenuPanel을 연다.

## 선택한 접근

1. 사용자 클릭 삭제를 기존 추가 Undo와 대칭인 복구 가능 제거로 기록한다. 제거된 명령, 슬롯, 순서를 Redo 스택에 보존하고 기존 비용·시뮬레이션 갱신 경로는 재사용한다.
2. 드래그 중에는 전투 예약 상태를 바꾸지 않는다. 포인터 아래 그룹이 삽입 위치와 행동의 `TimelineEntryCost`를 계산해 임시 레이아웃을 표시하고, 드롭 성공 때만 기존 예약 API를 호출한다.
3. 신규 스킬 드래그 시작 직전에 기존 프리뷰 자원 판정을 재사용한다. 기존 예약 이동은 이미 예약 비용에 포함된 행동이므로 이 검사를 적용하지 않는다.
4. 공용 ESC 컨트롤러가 활성 설정 패널을 메뉴보다 먼저 닫는다. 같은 프레임에는 MenuPanel 토글을 수행하지 않는다.

## 고려한 대안

- 모든 타임라인 편집을 범용 Command 히스토리로 재구성하면 장기 확장성은 높지만 이번 수정 범위를 크게 넘으므로 제외한다.
- 드래그 중 실제 예약 목록에 임시 명령을 넣었다가 취소하는 방식은 비용·시뮬레이션·네트워크 상태를 오염시킬 수 있어 제외한다.
- 설정 패널 자체 `Update`에서 ESC를 처리하는 방식은 공용 컨트롤러와 실행 순서 경쟁이 생기므로 제외한다.

## 범위와 제약

- 전투 결과 계산과 예약 명령 데이터 구조는 변경하지 않는다.
- 프리뷰는 UI 전용이며 드롭 전에는 비용과 전투 상태를 변경하지 않는다.
- 테스트는 `Assets/Tests/EditMode~/` 아래에만 작성한다.
- Unity 에디터 직접 제어와 batchmode 테스트는 수행하지 않는다.
- 문서 외 커밋, Push, PR, 브랜치 및 worktree 작업은 수행하지 않는다.

## 멀티플레이 경계

예약 명령은 기존 `PlayerReservedCommand`와 슬롯/순서 ID를 계속 사용한다. 드래그 프리뷰는 로컬 UI 상태이며 네트워크로 전송하지 않는다. 실제 드롭과 삭제는 기존 Steam 동기화 진입점을 유지하고, 이번 변경에서 네트워크 프레임워크나 새 프로토콜은 추가하지 않는다.

## 완료 조건

- 타임라인 행동 클릭 삭제 후 복구 버튼으로 동일 슬롯·순서에 복원된다.
- 1~3칸 행동을 신규 등록하거나 이동할 때 점유 칸 수만큼 공간과 하이라이트가 보이고 기존 행동이 미리 밀린다.
- 드래그 취소 시 실제 예약 상태와 레이아웃이 원래대로 돌아온다.
- 자원이 부족한 신규 행동은 드래그 아이콘과 프리뷰가 생성되지 않는다.
- 설정 패널이 열린 상태에서 ESC를 누르면 설정 패널만 닫히고 MenuPanel은 닫힌 상태를 유지한다.

## 드래그 하이라이트 시각 보정

- 런타임 단색 사각형 대신 `slot1_back`, `slot2_back`, `slot3_back` 스프라이트를 점유 칸 수에 맞춰 사용한다.
- 스프라이트는 `TimelineSlot.prefab`의 `BattleTimelineGroupUI`에 명시적으로 연결한다.
- 기본 색상은 순백색이며 알파는 0.35로 둔다. 색상은 인스펙터에서 조정 가능하게 한다.
- 기존 타임라인 행동 배경과 같은 평행사변형 실루엣을 유지하고 파란색 틴트는 사용하지 않는다.
