# 전투 전체 처치 치트 플래그 설계

## 목적

- `K`키로 모든 몬스터를 처치하는 디버그 입력을 빌드 전에 코드에서 쉽게 켜고 끈다.

## 설계

- `BattleDebugKillAllMonsters`에 `CheatEnabled` 정적 읽기 전용 플래그를 둔다.
- 기본값은 `true`로 설정한다.
- `Update()` 진입 시 플래그가 꺼져 있으면 입력을 처리하지 않는다.
- 실제 처치 처리와 디버그 창 버튼 호출 경로는 변경하지 않는다.

## 변경 방법

- 활성화: `CheatEnabled = true`
- 비활성화: `CheatEnabled = false`

## 영향

- K키 디버그 입력에만 영향을 준다.
- 전투 상태 처리 구조와 멀티플레이 동기화 경계는 변경하지 않는다.
