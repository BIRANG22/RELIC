# 데모 마지막 노드 종료 화면 설계

## 목적

데모 전투에서 마지막 노드를 완료한 뒤 진행 버튼을 누르면 선택할 다음 노드가 없는 지도로 돌아가지 않고, 데모 종료 메시지를 검은 화면 위에 표시한다.

## 조건

- `BattleRuntimeData.IsDemoBattle`이 `true`다.
- 현재 노드가 완료 상태다.
- 현재 노드에서 연결된 유효한 다음 노드가 하나도 없다.
- 일반 전투와 다음 노드가 남은 데모 전투는 기존 지도 복귀 흐름을 유지한다.

## 구조

- `DemoBattleEndingPolicy`가 런타임 데이터만 받아 데모 종료 여부를 판정한다.
- `BattleSceneController.ReturnToMap`은 방을 가리는 기존 전환 도중 정책을 검사한다.
- 종료 조건이면 지도를 열지 않고 씬에 미리 배치한 `DemoEndingPanel`을 활성화한다.
- `DemoEndingPanel`은 최상위 Canvas 아래의 전체 화면 검은 `Image`와 중앙 정렬 흰색 `TMP_Text`로 구성한다.

## 문구

```text
데모 버전의 여정은 여기까지입니다.

아직 끝나지 않은 이야기가 여러분을 기다리고 있습니다.
정식 버전에서 계속될 여정을 기대해 주세요!
```

## 범위

- 데모의 마지막 노드 종료 연출만 변경한다.
- 전투 결과, 노드 완료 상태, 보상 계산 및 랜덤에는 영향을 주지 않는다.
- 종료 화면에는 별도 버튼을 두지 않고 그대로 유지한다.

## 멀티플레이 영향

동기화된 전투 상태를 변경하지 않고 `IsDemoBattle`과 완료된 맵 상태를 읽어 표시만 결정한다.
