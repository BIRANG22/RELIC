# 턴 표시 문구 단순화 설계

## 조사 결과

- 전투 효과 정보 목록은 `battle.effect_info.turn_start_format` 키로 `N턴 시작`을 표시한다.
- 중앙 턴 인트로는 `ui.battle.progress` 값을 턴 번호 뒤에 붙여 별도로 문구를 만든다.
- `ui.battle.progress`는 범용 UI 키이므로 턴 인트로 전용 의미로 변경하면 다른 UI에 영향을 줄 수 있다.

## 권장 설계

- `battle.effect_info.turn_start_format`을 턴 표시 전용 포맷으로 유지하고, 모든 언어에서 시작 의미를 제거한다.
- 중앙 턴 인트로도 같은 전용 포맷 키를 사용한다.
- 한국어는 `{0}턴`, 영어는 `Turn {0}`, 중국어는 `第{0}回合`, 일본어는 `{0}ターン`, 스페인어는 `Turno {0}`으로 표시한다.
- `ui.battle.progress`는 변경하지 않는다.

## 영향 범위

- 표시 문자열과 UI 호출 경로만 변경한다.
- 턴 진행 상태, 전투 판정, 랜덤, 저장 데이터에는 영향을 주지 않는다.
