# 레드더스티움 전리품 표시명 설계

## 목표
- 전리품 패널에서 레드더스티움 보상이 나올 때 획득 수량을 이름 텍스트에 함께 보여준다.
- 예시는 `더스티움 x50` 형식이다.

## 설계
- 전리품 슬롯은 `BattleRewardData.GetDisplayName()`을 사용해 이름을 표시한다.
- `BattleRewardType.Remnant`인 경우 `Amount`를 이용해 `기존 이름 x수량` 형태로 반환한다.
- 이름이 비어 있으면 기본 표시명 `더스티움`을 사용한다.
- 아이템, 유물, 기억 보상 표시명은 기존 동작을 유지한다.

## 검증
- EditMode 테스트로 레드더스티움 보상 표시명이 수량을 포함하는지 확인한다.
- Unity batchmode 테스트는 프로젝트 규칙상 실행하지 않고, MSBuild로 컴파일을 검증한다.
