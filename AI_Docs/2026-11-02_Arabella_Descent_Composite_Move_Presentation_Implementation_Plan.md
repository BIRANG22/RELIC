# 아라벨라 하강 및 복합 이동 스킬 연출 구현 계획

1. 독립 이동과 스킬 내부 이동 효과의 공통 이동 연출 여부를 검증하는 EditMode 테스트를 추가한다.
2. 테스트가 기존 코드에서 실패하는지 확인한다.
3. 실행기에 연출 판정 정책을 적용하여 복합 스킬 내부 이동의 `PlayMove()` 호출을 차단한다.
4. 아라벨라 하강 시작 경계에서 Action Phase를 재생하도록 코루틴 호출 순서를 변경한다.
5. 관련 테스트와 C# 프로젝트 컴파일을 수행한다.
6. Unity 에디터 화면에서만 확인 가능한 실제 클립 전환 타이밍은 미검증 항목으로 보고한다.
