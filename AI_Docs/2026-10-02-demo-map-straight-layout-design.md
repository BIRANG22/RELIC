# 데모 맵 일자 배치 설계

## 목적

- 데모 전용 맵의 시작, 중간, 보스 노드를 하나의 수평 중앙선에 배치한다.
- 기존 맵 템플릿과 공용 맵 배치 규칙에는 영향을 주지 않는다.

## 적용 방식

- 데모 전용 `Test Manual Battle Map Template Demo` 에셋만 수정한다.
- 레이어 1~4의 활성 노드에 기존 커스텀 위치 옵션을 사용한다.
- 각 노드의 X 좌표는 공용 레이어 간격 100을 유지하고 Y 좌표는 0으로 통일한다.
- 시작 및 보스 노드는 기존 단일 노드 자동 중앙 배치를 유지한다.
- 노드 종류와 연결 정보는 변경하지 않는다.
