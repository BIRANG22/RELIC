# 탐사 결과 침식 슬롯 붉은 블러 설계

## 의도

`ExplorationResultPanel`의 각 `HardModeSlot` 아이콘 뒤에 고정형 붉은 블러를 표시해 선택된 침식 효과를 시각적으로 강조한다.

## 조사 결과

- 현재 침식, 획득 아이템, 캐릭터 장비 표시는 모두 공용 `StorageSlotUI.prefab`을 사용한다.
- 공용 슬롯 프리팹을 직접 수정하면 침식과 무관한 슬롯에도 블러가 노출된다.
- 침식 슬롯은 런타임에 생성된 뒤 재사용되므로, 전용 블러 프리팹을 슬롯별로 한 번 배치하면 풀링 흐름과 잘 맞는다.
- 기존 `Stage01/glow.png`는 UI Sprite로 임포트되어 있어 별도 텍스처 생성이나 임포트 설정 변경 없이 붉게 틴트할 수 있다.

## 접근 방식

- 선택: 붉은 블러 전용 UI 프리팹을 만들고 각 `HardModeSlot`의 아이콘 뒤에 한 번씩 배치한다. 공용 슬롯을 보존하면서 크기·색상·투명도를 프리팹에서 조절할 수 있다.
- 대안: 공용 `StorageSlotUI.prefab` 수정은 다른 아이템·유물·스킬 슬롯까지 영향을 주므로 제외한다.
- 대안: 코드에서 매번 `GameObject`와 `Image`를 직접 구성하면 빠르지만 아트 조정값이 코드에 고정되므로 제외한다.

## 설계

- `ExplorationResultHardModeBlur.prefab`은 `Image` 하나로 구성하고 `Stage01/glow.png`를 붉은색 반투명으로 표시한다.
- `raycastTarget`은 꺼 두고 기본 크기는 아이콘보다 넓은 정사각형으로 둔다.
- `ExplorationResultPanelUI`에 블러 프리팹 참조를 직렬화하고, `EnsureHardModeBlur`가 각 침식 슬롯에서 `HardModeRedBlur` 자식을 찾아 없을 때만 생성한다.
- 생성한 블러는 슬롯의 첫 번째 자식으로 이동해 아이콘 뒤에 렌더하고, 슬롯의 활성/비활성 수명주기를 그대로 따른다.
- 획득 아이템 및 캐릭터 슬롯 경로는 변경하지 않는다.

## 검증

- EditMode 소스/에셋 테스트로 블러 전용 프리팹, 붉은 색상, raycast 비활성, 씬 참조, 중복 생성 방지 구조를 확인한다.
- 런타임 및 테스트 포함 Editor C# 프로젝트를 컴파일한다.
- Unity 에디터에서 블러의 실제 크기와 투명도, 아이콘 뒤 렌더 순서를 수동 확인한다.

## 멀티플레이 경계

정산 화면의 시각 효과만 추가한다. 전투 상태, 침식 계산, 결과 데이터와 네트워크 동기화 경계에는 영향이 없다.
