# 공격 스킬 피해 문장 중복 수정 설계

## 문제

다중 공격 설명의 효과 토큰 `{E_Strike}`는 이미 `피해`로 표시된다. 그러나
`skill.sentence.deal.amount.multiple.final` 한국어 템플릿도 끝에 `피해를 준다`를
포함해, 최종 문장이 `피해를 ...회 피해를 준다`로 중복된다.

## 설계

- 다중 피해 최종 문장, 단일 피해 최종 문장, 연결 피해 문장에서 효과 토큰이
  이미 제공한 `피해`를 다시 쓰지 않도록 각각 `준다` 또는 `주고`로 고친다.
- `Localization.xlsx`를 원본으로 유지하고 Unity 한국어 String Table 및 신규 키
  기본값도 같은 문장으로 동기화한다.
- 회귀 테스트는 Excel 원본, Unity 한국어 테이블, 신규 키 기본값이 모두 중복 없는
  템플릿을 사용하는지 확인한다.

## 범위

문장 표시 데이터만 바꾸며 전투 수치, 타격 횟수, 상태 변경에는 관여하지 않는다.
