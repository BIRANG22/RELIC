# Event_08 각성 실패 종료 구현 계획

1. `Awaken` 성공 시 선택된 장착 기억 타깃을 세션 상태에 기록하는 테스트를 추가한다.
2. `Awaken` 실패 시 다음 이벤트 ID가 비고, 기록된 각성 타깃이 회수 콜백으로 전달되는 테스트를 추가한다.
3. `EventChoiceExecutionService`에 각성 성공 추적과 실패 회수 요청, 실패 시 다음 이벤트 차단을 구현한다.
4. `EventRoomController`에 회수 콜백을 연결하고 현재 장착 슬롯의 강화 기억을 ID 기준으로 비운다.
5. MSBuild로 런타임/에디터 어셈블리 컴파일을 확인한다.
