# 아라벨라 2페이즈 전용 카메라 연출 설계

## 의도

아라벨라가 2페이즈로 전환될 때 공용 전투 줌 대신 인스펙터에서 조절 가능한 전용 카메라 연출을 제공한다. 한 단계의 단순한 포커스부터 두 단계의 접근·강조 연출까지 지원하되, 범용 타임라인 시스템으로 확장하지 않는다.

## 목표

- `BattleCameraController`에 아라벨라 전용 설정 섹션을 제공한다.
- 1차 이동과 선택적인 2차 이동에 각각 위치 오프셋, 줌 거리/크기, 이동 시간, 이동 곡선을 설정한다.
- 단계 사이 유지 시간과 전환 애니메이션 종료 후 복귀 시간을 설정한다.
- 전용 연출을 비활성화하면 기존 `ZoomTo()`와 `ReturnPanelDown()` 동작을 유지한다.
- 전투 상태 변경과 카메라 연출의 분리를 유지한다.

## 비목표

- 임의 개수 키프레임, 카메라 회전, 흔들림, Cinemachine 타임라인을 추가하지 않는다.
- 아라벨라 외 몬스터의 카메라 동작을 변경하지 않는다.

## 검토한 방식

1. 단일 이동 전용 설정: 간단하지만 연출 변화 폭이 작다.
2. 선택형 2단계 이동: 설정 복잡도를 제한하면서 접근과 강조를 함께 표현할 수 있어 채택한다.
3. 키프레임 목록: 자유도는 높지만 이번 요구에 비해 인스펙터와 유지보수가 과도해 제외한다.

## 구현 구조

- `BattleCameraController`가 직렬화된 아라벨라 전용 설정과 전용 진입/복귀 코루틴을 소유한다.
- 각 단계는 활성 여부, XY 오프셋, Z 위치 또는 직교 크기, 이동 시간, 곡선을 가진다.
- `ArabellaPhaseTransition.CompletePendingTransitionRoutine()`은 전용 연출 활성 시 전용 API를 호출하고, 비활성 시 기존 API를 호출한다.
- 테스트는 설정 기본값과 전환 루틴의 전용 API 경계를 검증한다.

## 제약과 안전성

- 카메라/VFX는 전투 결과를 계산하지 않는다.
- 기존 씬 값은 직렬화 기본값 및 안전한 폴백으로 호환한다.
- 에디터 화면에서의 최종 구도는 수동 확인 항목으로 남긴다.
