# 전투 기억 보상 현지화 보완 설계

## 문제

- `Battle/Canvas/Skill_panel/Background/Name`은 한국어 `기억`을 정적으로 표시하며 선택 언어를 반영하지 않는다.
- 보상 목록의 기억 항목과 이벤트 결과 메시지가 한국어 문자열을 코드에서 직접 출력한다.
- `S_Core_07`, `S_Core_10`의 영어 설명 셀이 한국어 또는 깨진 문자열로 저장되어 영어 환경에서도 한국어 설명이 표시된다.

## 설계

1. 기억 보상 패널 제목은 `battle.reward.skill_panel_title` 키로 표시한다.
2. 보상 목록의 기억 항목은 `battle.reward.skill_acquired` 키로 표시한다.
3. 이벤트 결과의 기억 획득 메시지는 `event.result.memory_acquired_format` 키와 기억 이름을 조합한다.
4. `S_Core_07`, `S_Core_10`의 한국어 원문과 영어 번역을 `Localization.xlsx`에서 복구하고 Unity String Table에 동기화한다.
5. 동적 표시 TMP는 기존 보상 presenter가 소유하며 정적 로컬라이저가 값을 덮어쓰지 않게 한다.

## 검증

- 현지화 워크북에 세 키가 모든 지원 언어로 존재하는지 검사한다.
- 보상 UI 및 이벤트 결과 코드에 대상 한국어 하드코딩이 남지 않았는지 검사한다.
- 두 스킬의 영어 설명이 기대한 영어 문장인지 검사한다.
- 런타임 및 Editor C# 프로젝트를 컴파일한다.

## 멀티플레이 경계

표시 문자열과 번역 데이터만 변경한다. 보상 추첨, 지급, 인벤토리 상태, ID 및 전투 결과에는 영향이 없다.
