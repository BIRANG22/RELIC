# 턴 종료 기억 슬롯 기반 카르마 구현 계획

## 데이터 경계
- `ResourceType.None`을 카르마로 판정한다.
- 카르마의 `CurrentResource`는 내부 반 단위 정수이며 1이 표시값 0.5다.
- 다른 고유 자원은 기존 정수 단위를 유지한다.
- `UniqueResourceUnitVersion`으로 기존 저장값을 한 번만 2배 변환한다.
- 스킬 DB의 비용과 효과 값은 표시 단위를 유지하고 공용 정책에서 내부 단위로 변환한다.

## 실행 결과 집계
- 실제 행동 루틴에 진입한 활성 기억(Unique/Ability/Public/Core)만 기록한다.
- `CharacterId + TimelineSlotIndex` 집합으로 중복을 제거한다.
- 취소되었거나 실행 직전 사용자가 사망해 건너뛴 명령은 기록하지 않는다.
- 정상 실행에 진입한 뒤 대상이 이동했거나 빗나가 피해 결과가 0인 경우는 실행 무효가 아니므로 기록한다.
- 턴 종료 시 슬롯 수만큼 내부 단위 1씩, 최대 5단위(표시 2.5)를 지급한다.

## 표시와 경계
- 전투 HUD, 파티 HUD, 설정 패널은 공용 표시 변환과 반 점등을 사용한다.
- 턴 종료 예약 정리 직후 HUD를 다시 갱신해 예약 미리보기 값이 실제 획득값을 가리지 않게 한다.
- 저장/로비 스냅샷에는 내부값과 버전을 함께 보존한다.
- 기존 정수 회복/비용/장비 효과는 표시 단위에서 정책 API를 거쳐 적용한다.

## 검증
- 정책 EditMode 테스트와 런타임/에디터 어셈블리 컴파일을 수행한다.
- Unity 화면, 실제 턴 실행, Steam 재접속은 수동 검증 항목으로 보고한다.
