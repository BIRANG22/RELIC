# 로비 유물 구매 화면 공간 이동 효과 구현 계획

1. UI 오버레이에서 재생되는 범용 구체 프리팹과 제어 컴포넌트를 만든다.
2. 재생 시작 시 UI 시작점·도착점을 각각 화면 좌표로 고정하고, 그 좌표를 연결하는 포물선·잔상·색상 적용을 구현한다.
3. `LobbyRelicShopPresenter`의 기존 UI Equip 이동 연출을 새 프리팹 호출로 교체하고, `Lobby_Icon/Icon_04`(Storage) 착지 RectTransform을 인스펙터로 연결한다.
4. EditMode 테스트로 고정 화면 좌표 궤적과 프리팹 구성을 확인한다.
5. Unity 컴파일을 확인하고 씬에서 인스펙터 연결값을 검토한다.
