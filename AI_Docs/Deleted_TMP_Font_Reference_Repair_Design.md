# 삭제된 TMP 폰트 참조 복구 설계

## 문제

프리팹과 씬의 `TMP_Text`는 런타임에 `LocaleFontDatabase`의 폰트로 교체되기 전까지 직렬화된 초기 폰트와 머티리얼을 사용한다. 폰트 정리 과정에서 에셋이 삭제되었지만 YAML 참조가 남으면 클린 환경과 빌드에서 빈 글자, 잘못된 글리프 또는 머티리얼 불일치가 발생할 수 있다.

## 수정 원칙

- `m_fontAsset` 또는 `m_sharedMaterial`이 존재하지 않는 GUID를 가리키는 모든 프리팹·씬·에셋을 찾는다.
- 일반 본문 텍스트는 현재 `LocaleFontDatabase`의 기본 한국어/영문 폰트인 `Assets/Fonts/TMP/DungGeunMo SDF.asset`을 초기 폰트로 사용한다.
- 기존에 숫자나 별도 역할 폰트를 사용하도록 구성된 텍스트는 그 역할을 유지한다.
- 프로젝트 YAML에 존재하지 않는 TMP 폰트 또는 머티리얼 GUID가 다시 들어오지 않도록 EditMode 무결성 테스트를 둔다.

## 범위

- 삭제된 TMP 폰트 및 해당 서브 머티리얼 GUID 참조 교체
- YAML 무결성 테스트 추가
- 런타임 로컬라이징 및 전투 상태 로직은 변경하지 않는다.
