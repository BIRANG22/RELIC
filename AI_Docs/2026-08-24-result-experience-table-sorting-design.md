# 결과 패널 경험치 표 기준 정산 및 정렬 설계

## 목표

- 스테이지 종료 결과 패널의 캐릭터 경험치 계산을 기획 표 기준으로 변경한다.
- 결과 패널은 ESC로 여는 옵션 패널을 제외한 일반 패널보다 앞에 보이게 한다.
- 결과 패널 UI는 값을 표시만 하고, 전투 결과 계산은 데이터/서비스 계층에서 처리한다.

## 경험치 규칙

- 레벨업 필요 경험치: 레벨당 1000.
- 일반 전투방 클리어: 생존 90, 전투불능 45.
- 정예 전투방 클리어: 생존 160, 전투불능 80.
- 보스 전투방 클리어: 생존 350, 전투불능 175.
- 이벤트방 완료: 100.
- 몬스터 처치: 1회당 12.
- 가한 피해량: 5당 5.
- 받은 피해량: 5당 2.
- 버프 부여량: 5당 3.

## 데이터 기준

- 클리어 방 수는 `MapRuntimeData.GeneratedNodes`, `ClearedMapIds`, 현재 노드를 기준으로 계산한다.
- 승리 결과에서는 현재 노드를 클리어 집합에 포함하고, 패배 결과에서는 포함하지 않는다.
- 방별 생존 이력은 현재 저장되어 있지 않으므로, 캐릭터별 `DeathCount > 0`이면 전투불능 캐릭터 기준 보상을 적용한다.
- `BuffApplied`는 플레이어 버프 스킬 적용 흐름에서 시전자 `CharacterId` 기준으로 누적한다.

## 패널 정렬

- `ExplorationResultPanel`에 씬 배치 Canvas와 GraphicRaycaster를 추가한다.
- 결과 패널이 열릴 때 자체 Canvas의 `overrideSorting`과 높은 `sortingOrder`를 적용한다.
- ESC 옵션 패널은 기존 `UIManager`가 열릴 때 현재 최고 정렬값보다 높게 잡으므로 결과 패널 위에 올라올 수 있다.
- 결과 패널 정렬 컴포넌트는 런타임 생성하지 않는다.

## 멀티플레이 경계

- 새 경험치 계산은 UI가 아니라 서비스가 `MapRuntimeData`와 캐릭터 통계 스냅샷을 입력으로 계산한다.
- 전투 중 버프 부여량 기록은 `CharacterId`와 `BattleRuntimeData`를 사용하고, Scene Object를 장기 상태로 저장하지 않는다.
- UI는 계산 결과를 표시하고 귀환 시 적용 요청만 수행한다.
