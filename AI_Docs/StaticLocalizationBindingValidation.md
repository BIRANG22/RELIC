# 정적 텍스트 로컬리제이션 바인딩 검증

## 문제

정적 TMP 원문과 연결된 키의 `Korean(ko)`가 달라도 키가 존재하기만 하면 정상으로 처리되어 오래된 바인딩이 유지됐다. 씬 검사는 YAML의 문자열만 읽어 현재 키와 원문을 함께 검증하지 못했다.

## 설계

1. 프리팹과 씬의 실제 TMP·현재 키·계층 경로를 함께 검사한다. 닫힌 씬은 현재 씬을 교체하지 않는 Additive 방식으로 잠시 열고 검사 직후 닫는다.
2. TMP 원문과 현재 키의 `Korean(ko)`를 정규화해 교차 검증한다.
3. 일치하면 기존 키를 유지한다.
4. 불일치하면 에셋 경로와 오브젝트 계층 경로로 새 키를 만들고 기존 키의 원문은 변경하지 않는다.
5. 새 키를 일괄 추가하고 임포트한 뒤 모든 바인딩을 교체한다.
6. 교체 완료 후 프로젝트 사용처를 한 번만 다시 수집해 미사용 키를 일괄 제거한다.
7. 마지막 임포트로 워크북과 String Table을 동기화한다.

## 검증

- 불일치한 기존 키는 새 문맥 키로 교체한다.
- 원문이 일치하는 기존 키는 유지한다.
- 복구 후 미사용 키 제거가 한 번만 실행되는지 확인한다.
- 씬과 프리팹 모두 동일한 정책을 사용한다.
