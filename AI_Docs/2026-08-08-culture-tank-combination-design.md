# 배양조 조합 시스템 설계

## 목표

기존의 아이템별 시간제 연구를 제거하고, 배양조 슬롯 세 칸에 넣은 아이템의 A/B/C 타입 조합으로 즉시 결과를 생성한다. 조합 순서는 무시하며 결과를 클릭하면 전투 시작 버프를 획득한다.

## 데이터 구조

- `ItemData`는 `ResearchResult`, `EffectId`, `ValueRate`, `CountRate` 대신 `CultureType`만 가진다.
- `CultureTankCombinationDatabase`는 정규화된 세 타입 조합(`AAA`~`CCC`)을 키로 사용한다.
- 각 조합 엔트리는 `CombinationId`, 결과 아이콘, `EffectId`, `ValueRate`, `CountRate`, 적용 전투 횟수를 가진다.
- 런타임은 세 슬롯의 `TankId`와 `ItemId`, 완료된 `CompletedCultureTankCombinationId`만 저장한다.

## 동작 흐름

1. 슬롯 선택 후 인벤토리 아이템을 클릭하면 가방에서 한 개를 제거하고 슬롯 상태에 기록한다.
2. 채워진 슬롯을 클릭하면 아이템을 가방으로 반환한다.
3. 세 슬롯이 모두 찼고 미수령 결과가 없을 때만 합성이 가능하다.
4. 아이템 타입을 정렬하여 조합 DB를 조회한다. 조회 실패 시 입력 아이템을 보존한다.
5. 성공하면 입력 슬롯을 비우고 완료 조합 ID를 기록한다.
6. `completion`을 클릭하면 DB 수치로 전투 시작 효과를 생성하고 완료 상태를 비운다.

## 호환성과 동기화

- 구버전 시간제 연구 데이터는 최초 정규화 시 아이템을 가방에 돌려주고 제거한다.
- 상태 변경은 서비스 명령 메서드에서 수행하고 UI는 결과만 표시한다.
- 멀티플레이 공유 상태에는 안정적인 아이템 ID와 조합 ID만 직렬화한다.

## 초기 콘텐츠 배치

- `Item_001`부터 A/B/C를 반복 배정한다.
- 10개 조합에 기존 결과 이미지 1~10과 기존 효과 ID를 순서대로 배정한다.
- 모든 `ValueRate`, `CountRate` 기본값은 1이다.
