# 예약 이동 경로 우선 실행 구현 계획

1. 예약 경로의 축·방향별 구간 분리와 고정 코스트 정책을 EditMode 회귀 테스트로 정의한다.
2. `PlayerReservedCommand`에 결정론적인 구간 분리 로직을 추가한다.
3. `BattleActionSimulationService`의 목표 우선 재탐색을 제거하고 예약 구간을 순서대로 시뮬레이션한다.
4. `BattleActionRunner`가 막힌 구간 이후의 다른 방향 구간을 계속 실행하고 구간별 충돌을 한 번만 처리하도록 변경한다.
5. 이동 거리 기반 코스트 환급을 비활성화한다.
6. EditMode 테스트 소스와 런타임 어셈블리를 컴파일하고 정적 검증을 수행한다.
