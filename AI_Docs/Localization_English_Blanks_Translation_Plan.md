# 로컬리제이션 영어 공란 번역 계획

## 목표

`Assets/ExcelSource/Localization.xlsx`의 `Text` 시트에서 한국어 원문이 있으면서 영어가 비어 있는 셀만 영어로 번역한다.

## 범위와 설계

- 수정 대상은 `English(en)` 열의 공란 340개로 한정한다.
- 기존 영어 번역에서 동일한 한국어 문구와 게임 용어를 우선 재사용한다.
- `{ValueRate1}`, `{CountRate1}`, `{E_Strike}` 등의 런타임 토큰, 숫자, 줄바꿈, `+` 표기를 보존한다.
- Key, Id, 한국어 및 다른 언어 열, 셀 서식과 시트 구조는 변경하지 않는다.
- 원본 파일을 같은 경로에 저장한다.

## 검증

- 한국어가 존재하는 영어 공란이 0개인지 확인한다.
- 각 번역의 중괄호 토큰 집합이 한국어 원문과 같은지 확인한다.
- 수정 대상 외 셀 값이 이전과 같은지 확인한다.
- 저장된 XLSX를 다시 열어 시트 구조와 셀 값을 확인한다.
