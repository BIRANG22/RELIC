# 연속 동일 행동 연출 그룹 설계

## 목표

타임라인의 실제 실행 순서에서 `행동 주체 + SkillId + 대상 + 방향`이 동일한 비이동 행동이 연속되면 슬롯 경계를 넘어 하나의 연출 묶음처럼 재생한다.

각 예약 커맨드의 비용, 피해, 회복, 방어막, 상태효과, 장비 효과, 사망 판정과 결과 이벤트는 기존처럼 독립적으로 실행한다. 묶음은 전투 결과를 합치지 않고 연출 경계와 속도만 제어한다.

## 연속 행동 판정

실행 배치를 실제 순서인 `Swift 플레이어 -> 몬스터 -> 일반 플레이어` 순으로 펼친다. 다음 항목이 모두 같고 중간에 다른 행동이 없으면 같은 그룹이다.

- 플레이어: `CharacterId`
- 몬스터: `RuntimeId`
- `SkillId`
- 정렬한 `TargetGridIndices`
- 방향

이동 행동은 기존 이동 예약 병합 구조를 유지하며 연속 행동 그룹 대상에서 제외한다. 이동이나 다른 행동이 사이에 있으면 그룹을 끊는다. 슬롯 번호는 판정에 포함하지 않으므로 이전 슬롯의 마지막 행동과 다음 슬롯의 첫 행동도 연결할 수 있다.

## 연출 경계

그룹 크기가 2 이상일 때 첫 행동부터 마지막 행동까지 동일한 연출 속도 배율을 적용한다.

```text
그룹 시작: 카메라 포커스/줌 진입 1회
  행동 1: 행동 애니메이션, 스킬 VFX, 결과 판정, 대상 애니메이션/VFX
  행동 2: 행동 애니메이션, 스킬 VFX, 결과 판정, 대상 애니메이션/VFX
  ...
그룹 종료: 최종 임팩트, 히트스톱, 밀림/펄스, 카메라 복귀 1회
```

각 행동에서 유지하는 항목:

- 비용과 전투 결과 계산
- 공격, 피격, 가드, 회복 애니메이션
- 스킬 VFX, 히트 VFX, 사운드
- 피해/회복 팝업
- 상태 및 장비 트리거
- 타임라인 행동 소모 표시

그룹 내부에서 생략하는 외부 연출:

- 카메라 재진입과 중간 복귀
- 중간 행동의 카메라 임팩트와 화면 흔들림
- 중간 행동의 히트스톱
- 중간 행동의 밀림 유지 또는 상태 펄스 멈춤
- 배치 종료 후 불필요한 정지 구간

마지막 행동에서만 최종 외부 임팩트를 실행한다. 단독 행동은 기존 연출을 그대로 사용한다.

## 구성 요소

### BattleConsecutiveActionPlan

기존 배치를 읽어 커맨드별 `BattleConsecutiveActionInfo`를 만든다. 정보에는 그룹 크기, 그룹 내 인덱스, 시작/끝 여부와 속도 배율이 포함된다. 커맨드 객체나 전투 상태는 변경하지 않는다.

### BattleActionRunner

현재 실행 커맨드의 연출 정보를 참조해 카메라 진입, 외부 임팩트, 복귀와 후처리 대기의 실행 여부를 결정한다. 모든 판정 루틴은 기존 커맨드 단위로 호출한다.

### 연출 속도

`BattleTurnExecutor`에 연속 행동 속도 배율을 인스펙터 값으로 노출하며 기본값은 `1.5`다. 애니메이터, VFX와 연출용 대기 시간에만 적용하고 전투 수치 계산에는 사용하지 않는다.

## 네트워크 경계

새 전투 명령이나 네트워크 필드를 추가하지 않는다. 호스트가 전송한 기존 실행 배치를 양쪽에서 같은 순서와 안정적인 ID로 분석해 동일한 연출 계획을 만든다. 연출 그룹은 동기화 대상이 아니며 전투 결과에 영향을 주지 않는다.

## 예외 처리

- 실행 직전 주체가 사망하거나 대상이 사라지면 기존 규칙대로 커맨드를 건너뛴다.
- 계획 당시 그룹이었더라도 실행 불가로 남은 행동이 없어질 수 있다. 이 경우 이미 시작한 행동의 결과는 변경하지 않는다.
- 그룹 종료나 코루틴 중단 시 애니메이션/VFX 속도와 카메라 보류 상태를 반드시 복원한다.
- 이동 예약 병합과 이동 시각 경로는 변경하지 않는다.

## 검증

- 동일 플레이어 행동이 같은 슬롯에서 연속될 때 하나의 그룹이 되는지 검증한다.
- 슬롯 경계를 넘는 동일 행동이 같은 그룹이 되는지 검증한다.
- 주체, 스킬, 대상 또는 방향이 다르면 그룹이 끊기는지 검증한다.
- 이동이 그룹에 포함되지 않고 앞뒤 그룹을 끊는지 검증한다.
- 그룹의 첫 행동만 카메라 진입, 마지막 행동만 외부 임팩트와 복귀를 허용하는 정책을 검증한다.
- 기존 Unity EditMode 테스트와 C# 컴파일을 검증한다.
- Unity 에디터에서 실제 애니메이션, VFX, 카메라 연결감은 수동 확인 대상으로 남긴다.
