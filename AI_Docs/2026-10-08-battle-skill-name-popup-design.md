# 배틀 스킬명 머리 위 팝업 설계

## 목표

타임라인 실행 중 플레이어 캐릭터 또는 몬스터가 스킬을 사용할 때, 사용하는 유닛의 머리 위에 로컬라이징된 스킬명을 표시한 뒤 데미지 숫자와 같은 방식으로 사라지게 한다. 일반 이동 행동에는 표시하지 않는다.

## 설계

- 별도 컴포넌트 `BattleSkillTextPopupUI`가 월드 좌표 추적, Overlay Canvas, 유지·이동·축소·페이드아웃을 독립적으로 담당한다.
- `BattleDamageTextPopupUI`에는 스킬명 타입이나 설정을 두지 않아 데미지 팝업 조정이 스킬명에 영향을 주지 않게 한다.
- 스킬명 색상, 글자 크기, 위치, 유지 시간, 사라지는 시간, 이동 곡선과 크기는 `BattleSkillTextPopupUI` 인스펙터에서 독립적으로 조정한다.
- `BattleSkillNamePopupPresentation`이 플레이어·몬스터 명령의 표시 가능 여부와 로컬라이징된 표시명을 결정한다.
- 플레이어 일반 이동은 `ReservedMoveGridIndex >= 0`, 몬스터 일반 이동은 `TimelineNotation == Move`이므로 표시 대상에서 제외한다.
- 방향 이동이나 돌진 효과가 포함되어도 행동 자체가 스킬 실행 경로라면 스킬명을 표시한다.
- `BattleActionRunner`는 실제 유닛과 명령이 유효한 스킬 실행 시작 시점에 `BattleSkillTextPopupUI` 팝업만 요청한다. 팝업은 전투 결과 계산이나 실행 완료 조건에 관여하지 않는다.
- `Battle`, `DebugBattle`, `Battletest` 씬에는 데미지 팝업과 별도의 `BattleSkillTextPopupUI` 오브젝트를 배치한다.

## 검증

- EditMode 테스트로 플레이어 일반 이동 및 몬스터 이동 제외를 검증한다.
- EditMode 테스트로 플레이어·몬스터 스킬 이름의 표시 및 ID fallback을 검증한다.
- EditMode 테스트로 스킬명 전용 컴포넌트의 독립 설정과 데미지 팝업 타입 분리를 검증한다.
- C# 프로젝트 컴파일로 호출부와 UI 변경을 검증한다.
- Unity 에디터에서 실제 머리 위 위치, 색상, 크기, 사라지는 타이밍은 수동 확인 대상으로 남긴다.

## 멀티플레이 경계

명령과 안정적인 런타임 ID를 이용해 실행 유닛을 찾은 뒤 결과를 소비하는 UI 연출만 추가한다. 전투 상태, 명령 스냅샷, 랜덤 및 네트워크 동기화 데이터에는 변경이 없다.
