# 배틀 스킬 툴팁 효과 정보 안정화 설계

## 원인

`BattleCharacterPanelUI.LateUpdate()`가 `UpdateAllSkillEffectTooltips()`를 먼저 호출하고 `UpdateSkillTooltipPosition()`을 나중에 호출한다. 효과 정보가 아직 최종 크기와 위치가 확정되지 않은 스킬 정보 툴팁을 기준으로 생성되어 다음 레이아웃 갱신 때 위로 이동한다.

## 설계

- 스킬 툴팁 내용을 적용한 프레임에는 효과 정보 툴팁을 숨긴다.
- 먼저 Canvas와 스킬 툴팁 레이아웃·위치를 확정한다.
- 다음 프레임부터 효과 정보 툴팁을 생성한다.
- 매 프레임 갱신 순서를 `스킬 정보 위치 → 효과 정보 위치`로 유지한다.
- 효과 정보의 최종 위치 계산은 기존 `UpdateSkillEffectListPosition()`을 그대로 사용한다. 별도 아래 방향 배치를 적용하지 않는다.
- 툴팁을 숨기거나 새 스킬 내용으로 교체하면 안정화 상태를 초기화한다.

## 범위

- 전투 스킬 슬롯 호버 툴팁 표시 순서만 변경한다.
- 스킬 설명, 효과 계산, 전투 상태, 데이터 구조는 변경하지 않는다.

## 검증

- EditMode 테스트로 같은 프레임에는 효과 정보가 표시되지 않고 다음 프레임부터 허용되는지 검증한다.
- 런타임 및 에디터 어셈블리를 컴파일한다.
- Unity 화면에서 실제 이동이 사라졌는지는 에디터 수동 확인 대상으로 남긴다.
