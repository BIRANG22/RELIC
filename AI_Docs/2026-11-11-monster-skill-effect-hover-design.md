# 몬스터 행동 효과 텍스트 호버 설계

## 의도

전투 중 몬스터 정보 패널의 행동 설명에서 밑줄이 표시된 효과명에 마우스를 올리면, 해당 효과 하나의 설명 툴팁을 표시한다. 플레이어가 효과 의미를 현재 화면을 벗어나지 않고 확인할 수 있게 한다.

## 범위

- 대상은 실제 몬스터 클릭 화면에서 동적으로 생성되는 `MonsterInfoSkillItemUI.Detail`과 기존 `BattleMonsterInfoPanelUI.Skill_Details` 텍스트다.
- TMP 링크 ID `effecticon:<EffectId>`가 붙은 실제 렌더링 문자 영역만 호버 대상으로 삼는다.
- 호버한 효과 하나만 기존 `UnitStatusEffectTooltipUI`로 표시한다.
- 링크 밖으로 이동하거나 몬스터/스킬 선택이 바뀌거나 패널이 비활성화되면 툴팁을 닫는다.
- Effect DB에 존재하지 않는 ID와 잘못된 링크는 무시한다.

## 비범위

- 몬스터 행동 데이터, 효과 수치 계산, 전투 상태 변경은 수정하지 않는다.
- 별도 툴팁 프리팹이나 네트워크 동기화 상태를 추가하지 않는다.
- 몬스터 행동 설명이 아닌 플레이어 스킬·유물 설명 UI는 이번 범위에 포함하지 않는다.

## 접근 방식

1. **권장/선택: 전용 링크 호버 컴포넌트** — TMP가 제공하는 링크 좌표 판정을 사용하고 기존 효과 툴팁을 호출한다. 패널 코드의 책임을 작게 유지하고 링크 단위 판정이 명확하다.
2. 패널 `Update`에 직접 구현 — 파일 수는 줄지만 이미 큰 패널 클래스에 입력·툴팁 생명주기가 섞인다.
3. 설명 전체 Rect 호버 — 기존 유물 설명 방식과 유사하지만 어떤 밑줄 효과를 가리키는지 구분할 수 없어 요구사항과 맞지 않는다.

## 설계

`MonsterSkillEffectLinkTooltip`을 `Skill_Details`에 연결한다. 매 프레임 `TMP_TextUtilities.FindIntersectingLink`로 커서 아래 링크를 찾고 `effecticon:` 접두사의 Effect ID를 검증한다. ID가 바뀔 때만 Effect DB를 조회해 `StatusEffectRuntimeData` 하나를 만들고, 링크 문자 영역의 오른쪽 중앙을 화면 좌표로 변환하여 기존 툴팁을 표시한다. 동일 링크 안에서는 위치만 유지하고, 유효 링크가 아니면 즉시 숨긴다.

`MonsterInfoSkillItemUI`는 기존처럼 링크를 단순 밑줄 텍스트로 제거하지 않고, `<link="effecticon:...">`를 유지한 채 링크 내부에 `<u>`를 추가한다. 따라서 장막을 포함해 Effect DB에 등록된 모든 몬스터 행동 효과가 동일한 공통 호버 경로를 사용한다.

효과 정보 툴팁이 열린 동안에는 공통 툴팁의 피벗을 변경하지 않고, 활성 툴팁 `RectTransform`의 왼쪽 위 월드 좌표가 현재 마우스 포인터의 월드 좌표와 일치하도록 위치만 보정한다. 같은 효과 링크 안에서 커서가 움직여도 매 프레임 다시 보정하며, 다른 상태효과 툴팁의 배치에는 영향을 주지 않는다.

## 제약과 영향

- UI 표시 전용이며 `Command -> State Change -> Result/Event` 전투 흐름에는 관여하지 않는다.
- 씬/프리팹에 자동 컴포넌트를 저장하지 않고 패널이 명시적으로 바인딩한다.
- Unity 에디터 화면 확인은 수행하지 않으므로 실제 해상도별 위치·레이캐스트 체감은 미검증 항목으로 남긴다.
