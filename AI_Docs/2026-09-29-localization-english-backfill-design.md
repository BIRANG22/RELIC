# 로컬리제이션 영어 빈칸 보완 설계

## 목표

`Assets/ExcelSource/Localization.xlsx`의 `Text` 시트에서 키와 한국어 원문이 존재하지만 영어 셀이 비어 있는 항목을 모두 영어로 번역한다.

## 대상

- 대상 조건: Key 비어 있지 않음, Korean(ko) 비어 있지 않음, English(en) 비어 있음
- 조사 시점 대상 수: 1,225개
- 기존 영어 번역 452개는 수정하지 않는다.
- 한국어 원문이 비어 있는 68개 행은 번역하지 않는다.

## 번역 원칙

1. 기존 영어 번역에서 사용 중인 게임 용어와 대소문자를 우선한다.
2. 동일한 한국어 문구는 문맥이 같은 경우 동일한 영어 번역을 재사용한다.
3. 이벤트 대사와 선택지는 영어 사용자에게 자연스럽게 읽히도록 문맥 중심으로 번역한다.
4. `{0}`, `{ValueRate1}` 같은 런타임 치환 토큰은 이름과 개수를 그대로 유지한다.
5. 줄바꿈, `%`, 숫자, `+` 표기와 데이터 식별 의미를 보존한다.
6. 워크북의 시트 구조, 행 순서, 서식 및 다른 언어 열은 변경하지 않는다.

## 검증

- 대상 1,225개 영어 셀이 모두 채워졌는지 확인한다.
- 수정 전후 기존 영어 셀 값이 동일한지 확인한다.
- 한국어와 영어 사이의 치환 토큰 집합이 동일한지 확인한다.
- 영어 셀에 한글이 남은 항목을 검사하고 고유명사 여부를 확인한다.
- 워크북 재계산 후 재로드하여 저장 결과를 확인한다.
