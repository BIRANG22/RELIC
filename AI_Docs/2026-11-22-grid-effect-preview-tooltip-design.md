# 그리드 효과 미리보기 툴팁 호버 설계

## 의도

아라벨라 낙인(`GR_Stigma`) 배치 미리보기에서도 실제 배치된 그리드 효과와 동일하게 이름과 설명 툴팁을 확인할 수 있게 한다.

## 원인

`BattleGridEffectController.TryCreatePlacementPreview`는 미리보기의 전투 상호작용을 막기 위해 모든 Collider/Collider2D를 비활성화한다. 이후 `GridEffectHoverTarget.Attach`가 호출되지만 기존의 비활성 `BoxCollider2D`를 호버 대상으로 선택하며, `Update`는 비활성 콜라이더에 대해 호버 판정을 중단한다. `Attach`에 전달되는 `fallbackSize`는 현재 사용되지 않는다.

## 목표와 비목표

- 미리보기 전투용 콜라이더는 비활성 상태를 유지한다.
- `fallbackSize`가 제공되고 사용 가능한 활성 콜라이더가 없을 때만 툴팁 전용 `BoxCollider2D`를 만든다.
- 실제 배치된 그리드 효과의 기존 활성 콜라이더 동작은 변경하지 않는다.
- 툴팁 외 전투 상태, VFX 표현, 충돌 판정은 변경하지 않는다.

## 검토한 접근

1. 기존 콜라이더 재활성화: 변경은 작지만 미리보기 상호작용 차단 의도를 깨뜨릴 수 있어 제외한다.
2. `fallbackSize` 기반 전용 호버 콜라이더 생성: 비활성 전투용 콜라이더를 보존하면서 툴팁만 복구할 수 있어 채택한다.
3. 프리팹에 별도 콜라이더 추가: 특정 프리팹만 고치며 같은 미리보기 생성 경로의 재발을 막지 못해 제외한다.

## 설계

`GridEffectHoverTarget`은 활성화된 `BoxCollider2D`만 기존 호버 대상으로 선택한다. 활성 콜라이더가 없고 `fallbackSize`가 유효하면 대상 아래에 툴팁 전용 자식 오브젝트와 trigger `BoxCollider2D`를 생성한다. 이 콜라이더는 직접 `OverlapPoint`로만 조회하며 전투 명령이나 상태 변경에는 관여하지 않는다.

## 검증

EditMode 회귀 테스트로 비활성 원본 콜라이더가 그대로 유지되는지, 활성 툴팁 전용 콜라이더가 지정 크기로 생성되는지 확인한다. 이후 프로젝트 컴파일과 변경 파일 정적 검사를 수행한다.
