# 수동 전투 맵 가변 보스 레이어 설계

## 목적

수동 전투 맵 템플릿이 0~13 레이어에 고정된 구조를 완화하여, 템플릿별로 더 짧은 맵을 구성할 수 있게 한다. 기존 템플릿은 13번 레이어를 보스로 유지하고 데모 템플릿은 5번 레이어에서 종료한다.

## 설계

- `ManualBattleMapTemplate`에 템플릿별 `BossLayerIndex` 설정을 둔다.
- 지원 범위는 기존 직렬화 필드가 제공하는 1~13 레이어다.
- 시작 노드는 항상 0번 레이어에 둔다.
- 중간 레이어는 1번부터 `BossLayerIndex - 1`까지만 생성한다.
- 보스 노드 인덱스는 기존 레이어당 4개 예약 규칙으로 계산한다.
- 기본 보스 레이어는 13으로 두어 기존 에셋의 동작과 노드 인덱스를 보존한다.
- 런타임 키 해시는 선택된 전체 레이어 수를 반영한다.

## 데모 템플릿

`Test Manual Battle Map Template Demo`는 마지막 레이어를 5로 설정한다. 생성되는 단일 경로는 `Layer 0(Special) → 1(Common) → 2(Special) → 3(Shop) → 4(Rest) → 5(Elite)`이며, 마지막 노드 타입은 에셋에 설정된 `Elite`를 그대로 사용한다. Layer 5 이후의 중간 레이어 데이터는 에셋에 남아 있어도 생성 시 제외된다.

## 검증

- 기본 템플릿의 보스가 레이어 13, 노드 49인지 확인한다.
- 보스 레이어를 11로 설정했을 때 레이어 12·13이 생성되지 않고 보스가 노드 41인지 확인한다.
- 런타임 코드와 에디터 테스트 코드가 컴파일되는지 확인한다.

## 멀티플레이 영향

맵 상태는 기존과 동일하게 안정적인 `NodeIndex`와 `LayerIndex`로 표현된다. 동기화 구조나 네트워크 프레임워크에는 변경이 없으며, 템플릿 런타임 키가 레이어 수를 포함하므로 서로 다른 길이의 템플릿을 구분할 수 있다.
