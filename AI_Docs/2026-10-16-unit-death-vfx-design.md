# 유닛 사망 VFX 연결 설계

## 목표

플레이어 캐릭터와 몬스터가 사망 애니메이션에 진입할 때 유닛별로 지정한 VFX를 한 번 재생한다.

## 구조

- 기존 사망 판정과 HP 변경 흐름은 유지한다.
- 모든 기존 사망 연출 진입점인 `BattleUnitAnimator.PlayDead()`가 사망 애니메이션과 VFX 재생을 함께 담당한다.
- `BattleUnitAnimator`에 `BattleVfxEntry deathVfx`를 직렬화하여 각 전투 프리팹에서 리소스와 렌더 옵션을 조정할 수 있게 한다.
- 몬스터는 데미지 표현과 `BattleDeathService` 양쪽에서 `PlayDead()`가 호출될 수 있으므로, 컴포넌트 내부에서 사망 연출을 한 번만 허용한다.
- 기존 `SpawnVfx` 경로를 재사용하여 스폰 위치, 방향 반전, 정렬, 수명 설정을 동일하게 적용한다.

## 데이터 흐름

`Command -> HP/사망 State Change -> PlayDead 결과 표현 -> Dead 애니메이션 + Death VFX`

VFX는 사망 여부를 계산하거나 상태를 변경하지 않는다. 이미 확정된 사망 결과만 로컬에서 표현한다.

## 프리팹 작업 방식

- 캐릭터 및 몬스터 전투 프리팹의 `BattleUnitAnimator > Death VFX`에서 VFX 프리팹과 렌더 옵션을 연결한다.
- 리소스가 지정되지 않은 유닛은 기존처럼 사망 애니메이션만 재생한다.
- 현재 요청에는 실제 사망 VFX 리소스 지정이 없으므로 코드 연결 슬롯만 추가하고 기존 프리팹 동작은 보존한다.

## 검증

- `PlayDead()`를 두 번 호출해도 Death VFX 인스턴스가 하나만 생성되는지 EditMode 테스트로 검증한다.
- Death VFX가 비어 있어도 예외 없이 기존 사망 애니메이션 경로가 유지되는지 검증한다.
- C# 프로젝트 컴파일과 변경 파일 직렬화 상태를 확인한다.
