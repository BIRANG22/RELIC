# BGM 동시 크로스페이드와 전투 배속 피치 분리 설계

## 의도

BGM 상태 변경 시 무음 구간 없이 기존 곡과 새 곡이 겹쳐 전환되게 하고, 전투 연출 배속이 VFX 효과음의 음높이를 변경하지 않게 한다.

## 목표

- 기존 BGM 페이드아웃과 새 BGM 페이드인을 같은 시점에 시작한다.
- 메인 BGM과 부가 레이어를 하나의 재생 뱅크로 함께 전환한다.
- 전환 도중 새 요청이 들어와도 들리는 음량에서 자연스럽게 다음 전환으로 이어간다.
- VFX 효과음의 데이터 피치와 랜덤 피치는 유지하되 전투 연출 배속을 피치에 곱하지 않는다.

## 비목표

- AudioMixer 에셋이나 Snapshot 신규 구성
- 효과음 길이 자체의 타임 스트레칭
- UI/일반 SFX의 재생 정책 변경

## 접근

1. 기존 단일 소스에서 순차 페이드: 구조는 단순하지만 동시 크로스페이드가 불가능하다.
2. AudioMixer Snapshot: 강력하지만 믹서 에셋 설정과 씬 연결이 추가된다.
3. 두 BGM 소스 뱅크를 번갈아 사용: 현재 코드의 레이어·루프 정책을 재사용하면서 동시 전환과 중간 요청을 처리할 수 있다.

선택: 3번. 활성 뱅크와 대기 뱅크 각각에 메인 및 레이어 소스를 두고, 전환 동안 독립 볼륨을 보간한다. 피치는 `VfxSoundCue` 자체 값만 사용한다.

## 검증

- 순수 정책 테스트로 두 페이드 진행률과 배속 독립 피치를 검증한다.
- AudioManager 테스트로 두 소스가 동시에 재생되고 최종적으로 새 소스만 남는지 검증한다.
- 런타임·에디터 프로젝트를 컴파일한다.
- 실제 청감과 전환 도중 연속 요청은 에디터 수동 검증 항목으로 남긴다.
