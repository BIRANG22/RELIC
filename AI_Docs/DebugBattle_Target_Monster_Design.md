# DebugBattle 효과 테스트용 몬스터 설계

## 목표

DebugBattle 씬에만 아무 행동도 하지 않는 효과 테스트용 몬스터 한 마리를 생성한다. 최대 HP와 현재 HP는 999이며, 생존한 상태로 플레이어 턴이 끝날 때마다 HP를 999로 회복한다.

## 동작

- 일반 몬스터 DB, 저장 데이터, 실제 Battle 씬에는 디버그 몬스터 데이터를 추가하지 않는다.
- 기존 몬스터 프리팹 하나를 외형 및 HUD 연결용으로 재사용한다.
- DebugBattle 로더는 저장된 `MapRuntimeStore`의 몬스터 구성을 사용하지 않고 테스트 몬스터 한 마리만 생성한다.
- 런타임 식별자는 디버그 전용 ID를 사용하고 `MaxHP`, `CurrentHP`를 999로 설정한다.
- 스폰 직후 해당 `MonsterUnit`의 AI를 비활성화하여 이동과 공격 계획을 생성하지 않는다.
- `BattleTurnExecutor.PlayerTurnReturned` 이벤트에서 살아 있는 디버그 몬스터의 HP를 999로 복구하고 HUD를 갱신한다.
- 한 턴 중 HP가 0이 되면 일반 몬스터와 동일하게 사망 및 승리 처리한다.
- 씬 종료 또는 오브젝트 파괴 시 턴 이벤트 구독을 해제한다.

## 구조

- DebugBattle 전용 구성 컴포넌트가 기존 스폰 경로를 통해 몬스터를 생성하고 런타임 값을 덮어쓴다.
- HP 회복 여부는 런타임 ID로 판별하고, 행동은 해당 런타임 표적의 AI만 비활성화한다.
- 일반 전투 로직은 디버그 플래그가 없는 몬스터에 대해 기존 동작을 유지한다.

## 검증

- 런타임 데이터의 HP가 999로 구성되는지 검사한다.
- 생존 상태의 턴 종료 회복과 사망 상태 미회복을 검사한다.
- 런타임/에디터 어셈블리를 빌드한다.
- Unity 에디터에서 DebugBattle 진입 후 몬스터가 행동하지 않고 턴 종료마다 HP가 복구되는지 확인한다.
