# 전투 보상 삭제 버튼 레이아웃 조정

## 조사 결과

- 영어 `Extract` 문구가 한국어보다 길지만 아이콘과 값 텍스트는 기존 위치를 유지해 서로 겹쳤다.
- 버튼 폭 확장 후 좌우 장식 이미지의 기본 위치는 `-130 / 130`으로 변경됐지만, 호버 목표는 `-105 / 105`에 남아 호버 시 장식이 콘텐츠 안쪽으로 이동했다.

## 적용 설계

- 추출 아이콘 X 위치를 `64.2`에서 `85`로 이동한다.
- 값 텍스트 X 위치를 `136.6`에서 `157`로 이동한다.
- 삭제·확인 버튼 좌우 장식 이미지의 기본 X 위치를 `-125 / 125`, 호버 X 위치를 `-135 / 135`로 설정해 버튼 안쪽 여백을 유지하면서 바깥쪽으로 10px 퍼지게 한다.
- 전투 계산이나 보상 값 산출 코드는 변경하지 않고 씬 UI 배치 데이터만 조정한다.

## 검증 계획

- EditMode 회귀 테스트로 씬의 콘텐츠 및 호버 위치 값을 검증한다.
- 테스트 어셈블리 컴파일과 변경 파일 형식 검사를 수행한다.
