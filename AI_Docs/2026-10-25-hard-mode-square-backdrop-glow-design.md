# HardModeSlot 사각 외곽 글로우 설계

## 의도

슬롯 뒤에 배치된 외곽 블러가 불투명한 사각 슬롯에 가려지지 않도록, 원형 글로우를 슬롯보다 큰 사각형 글로우로 교체한다.

## 접근 방식

- 선택: 투명 배경의 전용 사각 글로우 Sprite를 추가해 기존 외곽 블러 프리팹에서 사용한다. 슬롯 바깥 네 변과 모서리에 동일한 붉은 발광이 남는다.
- 제외: 기존 원형 글로우 확대는 모서리와 변의 발광 밀도가 낮아 현재 문제를 반복한다.
- 제외: 단색 사각형 확대는 블러가 아니라 판처럼 보여 연출 의도에 맞지 않는다.

## 설계

- 기존 아이콘 내부 원형 블러와 외곽 블러의 생성·동기화·형제 순서 로직은 유지한다.
- 새 Sprite는 투명 배경, 텍스트 없음, 중앙에서 가장자리 바깥으로 부드럽게 감쇠하는 정사각형 붉은 글로우로 만든다.
- 외곽 블러 RectTransform은 `160 x 160`으로 설정한다. `80 x 80` 슬롯보다 충분히 커서 슬롯 뒤에서도 사방으로 보이게 한다.
- `raycastTarget = false`를 유지한다.

## 검증

- 프리팹의 크기·Sprite·색상·입력 차단 설정을 EditMode 에셋 테스트로 검증한다.
- Editor 프로젝트 컴파일과 `git diff --check`를 수행한다.
- Unity 화면에서 네 변과 모서리의 가시성을 최종 확인한다.

## 멀티플레이 영향

정산 UI의 이미지 리소스와 크기만 바꾸므로 전투 상태 및 동기화에는 영향이 없다.
