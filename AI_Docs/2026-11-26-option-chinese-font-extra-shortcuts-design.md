# 옵션 중국어 글꼴 및 추가 전투 단축키 설계

## 의도

- 간체·번체 중국어에서 옵션 패널의 동적 문구가 네모로 표시되지 않게 한다.
- 기존 전투 입력인 `Tab`, `1~5`, `Space`를 조작 탭에서 변경할 수 있게 한다. `B`는 포함하지 않는다.

## 조사 결과

- 옵션 동적 텍스트는 탭에서 복사한 공용 숫자 폰트를 원본 폰트로 기억한다. 전역 폰트 적용기는 이 폰트를 `number/preserve` 역할로 판단하여 중국어 본문 폰트로 교체하지 않는다.
- `Tab`은 캐릭터 순환, `1~3`은 캐릭터 직접 선택과 타임라인 슬롯 선택, `4~5`는 타임라인 슬롯 선택, `Space`는 턴 실행에 사용된다.
- 타임라인 슬롯 표기는 `ReserveTurnSlotUI`가 숫자를 직접 작성한다.

## 권장 설계

- 옵션의 번역 문구는 `LocaleTMPFontGuard.PrepareLocalized`로 현재 로케일의 본문 폰트를 명시 적용한다. 키 값 자체는 공용 숫자 폰트를 유지한다.
- `BattleShortcutAction`에 `CharacterCycle`, `TimelineSlot01~05`, `EndTurn`을 추가한다.
- `1~3` 설정은 기존처럼 캐릭터 직접 선택과 해당 타임라인 슬롯 선택 양쪽에 공통 적용한다.
- 튜토리얼의 허용 키 비교도 고정 키 대신 설정된 키를 사용한다.
- 중복 허용, 양쪽 반응, 빨간 표시 정책은 기존 단축키와 동일하게 유지한다.

## 비목표

- `B` 단축키 추가.
- 전투 명령/상태 계산 방식 변경.
- 로비 단축키 변경.
