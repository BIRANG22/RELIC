# 배틀 UI 코너 피드백 설계

## 목표

스킬 버튼 클릭과 타임라인 예약 성공을 서로 구분되는 흰색 코너/글로우 효과로 전달한다.

## 구조

- `BattleUiCornerFeedback`는 UI 메시만 그리는 프레젠테이션 전용 컴포넌트다.
- 스킬 클릭 프리팹은 네 모서리를 짧게 표시하고 바깥으로 확대하며 사라진다.
- 타임라인 등록 프리팹은 중앙 백색 섬광과 길이가 다른 다중 테이퍼 광선을 아이콘 사방으로 빠르게 확산한 뒤 사라지게 한다.
- 광선은 왼쪽 아래와 오른쪽 위 방향이 평균적으로 가장 길고 반대 대각선으로 갈수록 짧아지며, 고정된 불규칙 편차로 균등한 인상을 피한다.
- 색상, 여백, 선 두께, 모서리 길이, 글로우, 재생 시간과 스케일은 프리팹 인스펙터에서 조절한다.

## 트리거

- 실제 배틀 HUD의 `BattleCharacterSkillHoverUI`가 선택 피드백을 받을 때 해당 스킬 아이콘에 클릭 피드백을 생성한다.
- 별도 스킬 목록 UI의 `SkillListSlotUI`에도 동일한 클릭 피드백을 유지한다.
- `BattleTimelineController`가 플레이어 명령 등록에 성공하여 타임라인을 갱신한 뒤 정확한 명령 아이콘에 등록 피드백을 생성한다.
- 실패한 예약과 네트워크 스냅샷 단순 복원에는 피드백을 생성하지 않는다.

## 멀티플레이 경계

피드백은 기존 명령 등록 성공 결과를 읽어 재생하는 로컬 UI 연출이다. 전투 명령, 상태, 비용, 실행 순서에는 영향을 주지 않는다.
