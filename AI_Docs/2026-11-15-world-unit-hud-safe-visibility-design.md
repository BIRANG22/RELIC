# 월드 유닛 HUD 안전 표시 설계

## 목적

아군과 적군이 공통으로 사용하는 `HUDSlot`이 생성 직후 또는 추적 위치 계산 실패 시 화면 중앙이나 이전 위치에서 한 프레임 노출되는 문제를 제거한다.

## 범위

- `HUDSlot`은 생성·비활성화 직후 항상 숨김 상태를 보장한다.
- 표시 요청과 실제 렌더링을 분리하며, 유효한 추적 위치를 계산한 경우에만 표시한다.
- 타깃, 카메라, 콜라이더가 늦게 준비되는 경우 다음 프레임에 다시 계산한다.
- 아군·적군 HUD 제거 전 즉시 숨기고, 런타임 몬스터 해제 시 연결 HUD도 정리한다.
- 현재 비활성인 `WorldFollowHUD`는 위치 갱신 주체로 사용하지 않는다.

## 고려한 접근

1. 프리팹의 CanvasGroup alpha만 0으로 저장: 최초 노출은 줄지만 런타임 재활성화와 위치 계산 실패를 막지 못한다.
2. `HUDSlot`을 단일 위치·표시 주체로 강화: 현재 실사용 구조를 유지하면서 모든 표시 경로에 동일한 안전 조건을 적용할 수 있다. 채택.
3. `WorldFollowHUD`를 활성화해 위치 계산을 이전: 두 컴포넌트의 책임 재구성이 커지고 기존 표시 상태·애니메이션과 충돌 위험이 있어 이번 범위에서 제외한다.

## 동작 규칙

- `Awake`와 `OnDisable`은 애니메이션 상태와 무관하게 CanvasGroup을 즉시 숨긴다.
- 추적형 HUD의 `Show`와 값 변경 표시는 위치 계산 성공 전에는 표시 요청만 유지하고 alpha는 0으로 둔다.
- 추적 위치 계산 실패나 카메라 뒤 타깃은 기존 좌표를 노출하지 않는다.
- 콜라이더가 바인딩 시점에 비활성이면 활성화된 후 머리 위치 오프셋을 다시 획득한다.
- 제거 경로에서는 지연 가능한 일반 `Hide`가 아니라 강제 숨김 후 제거한다.

## 비목표

- HUD 외형, 표시 시간, HP/보호막 애니메이션 변경
- 캐릭터 또는 몬스터 전투 상태 변경
- `WorldFollowHUD`의 전면 재설계

## 멀티플레이 경계

UI 표시 위치와 가시성만 변경한다. Command, 전투 State Change, Result/Event 및 랜덤 처리에는 영향이 없다.
