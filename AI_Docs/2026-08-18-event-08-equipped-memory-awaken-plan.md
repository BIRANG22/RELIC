# Event_08 장착 기억 각성 패널 구현 계획

1. EventChoice 실행 테스트를 먼저 추가한다.
   - 선택 기억 대상이 없으면 `Awaken` 선택지가 막힌다.
   - 강화 가능한 장착 기억이 있으면 선택지가 가능하다.
   - 선택된 장착 기억만 강화 콜백으로 전달된다.
2. Event_08 패널 UI 테스트를 추가한다.
   - 씬 참조가 있을 때 후보 수만큼 옵션을 만든다.
   - 선택/취소 콜백과 닫힘 동작을 확인한다.
3. 실행 서비스에 선택 기억 대상 타입과 콜백을 추가한다.
4. EventRoomController에 후보 수집, 패널 열기, 선택 실행, 강화 적용을 연결한다.
5. Battle 씬의 DataEventRoot 아래에 Event_08 기억 선택 패널을 비활성 상태로 배치한다.
6. EditMode 테스트와 C# 빌드로 검증한다.
