# 배틀 맵 노드 정보 상시 표시 및 호버 피드백 설계

## 조사 결과

- `BattleMapNodeInfoPresenter.Awake()`와 호버 종료 콜백이 `Hide()`를 호출하며 `Node_Info` 오브젝트 자체를 비활성화하고 있다.
- `Node_Info`의 배경 `Image`, 이름/설명 `TMP_Text`, 아이콘 `Image`가 모두 레이캐스트 대상으로 설정되어 있어 겹치는 노드의 포인터 입력을 차단할 수 있다.
- 노드 호버 전달 컴포넌트는 정보 갱신만 수행하고 아이콘 시각 피드백은 제공하지 않는다.

## 설계

- `Node_Info`는 활성 상태를 유지하고, 호버가 없을 때 기본 안내 문구와 비어 있는 아이콘 상태를 표시한다.
- 호버 종료 시 오브젝트를 끄지 않고 기본 안내 상태로 복구한다.
- 정보 패널에 속한 그래픽의 `raycastTarget`을 비활성화해 지도 노드 입력을 가로채지 않도록 한다.
- `MapNodeHoverRelay`가 노드의 `Icon` 자식만 기준 크기의 1.1배까지 부드럽게 확대하고 종료 시 복구한다.
- 노드 선택 가능 여부와 호버 정보/연출 여부를 분리한다.

## 멀티플레이 경계

표시 UI와 포인터 연출만 변경한다. 맵 상태, 노드 선택 명령 및 전투 결과에는 영향을 주지 않는다.
