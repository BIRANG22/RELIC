# 런타임 텍스트 로컬라이제이션 재동기화 설계

## 문제

언어 변경 이벤트 시점에 아직 생성·연결되지 않았거나, 같은 프레임에 다른 UI 코드가 다시 쓴 TMP는 선택 언어 적용을 놓칠 수 있다. 오브젝트를 껐다 켜면 `OnEnable` 갱신이 다시 실행되어 뒤늦게 적용된다.

## 설계

- 선택 로케일 변경 후 문자열 테이블 로드가 끝나면 모든 `LocalizedTMPText`와 `DynamicLocalizedTMPText`를 현재 로케일로 재동기화한다.
- 비활성 오브젝트도 포함해 이후 활성화 때 한국어 원문이 노출되지 않게 한다.
- 같은 프레임의 다른 텍스트 작성자가 덮어쓰는 경우를 위해 한 프레임 뒤 한 번 더 재동기화한다.
- 각 텍스트 컴포넌트의 기존 최신 요청 게이트는 유지하여 오래된 언어 요청을 폐기한다.
- 런타임 TMP 변경 감지는 기존 `TMPro_EventManager.TEXT_CHANGED_EVENT` 경로를 유지한다.

## 검증

- 언어 변경 이벤트 뒤 생성된 비활성 텍스트를 오브젝트 토글 없이 명시 로케일로 갱신하는 EditMode 회귀 테스트를 추가한다.
- 런타임 및 에디터 어셈블리 컴파일, 씬 연결, diff 무결성을 확인한다.

## 멀티플레이 경계

표시용 TMP와 로컬라이제이션 갱신만 변경하며 게임 상태 및 전투 결과에는 영향을 주지 않는다.
