# 룬 장착 및 전투 캐릭터 변경 사운드 설계

## 의도

입력 방식에 묶인 효과음을 실제 상태 변경에 묶어, 룬은 클릭과 드래그 모두 장착 성공 시 같은 소리가 나고 전투 캐릭터는 어떤 UI 경로로 바꾸더라도 같은 소리가 나게 한다.

## 범위

- 룬 장착 성공 후 저장·UI 갱신·변경 이벤트·장착음을 하나의 완료 처리로 모은다.
- 드롭 핸들러에 직접 있던 장착음은 제거한다.
- 전투 캐릭터 선택은 기존 선택 캐릭터에서 다른 유효 캐릭터로 실제 변경될 때만 `ui.normal.click`을 재생한다.
- `BattleCharacterPanel` 캐릭터 오브젝트의 `DBAudioSource` 클릭음은 런타임 바인딩 시 비활성화해 중복 재생을 막는다.

## 비범위

- 룬 해제음, 장착 실패음, 초기 전투 캐릭터 자동 선택음은 추가하지 않는다.
- 전투 상태 계산이나 네트워크 동기화 흐름은 변경하지 않는다.

## 고려한 접근

1. 각 클릭·드롭·탭 핸들러에 효과음을 추가: 빠르지만 새 입력 경로가 생길 때 다시 누락될 수 있어 제외한다.
2. 저장 또는 데이터 저장소 변경에 효과음을 추가: 초기 로드와 시스템 갱신에도 소리가 날 수 있어 제외한다.
3. 사용자 동작으로 확정된 장착 완료 처리와 캐릭터 선택 변경 지점에서 재생: 상태 변화 의미와 가장 가깝고 입력 방식에 독립적이므로 채택한다.

## 검증

- EditMode 테스트로 룬 장착 완료 처리의 재생 조건과 캐릭터 변경 판정을 검증한다.
- 프로젝트 C# 컴파일과 관련 테스트를 실행한다.
- Unity 에디터 화면에서의 실제 청음은 자동 검증 범위에서 제외한다.
