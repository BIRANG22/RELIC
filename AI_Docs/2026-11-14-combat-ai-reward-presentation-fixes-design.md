# 전투 AI·보상·연출 결함 수정 설계

## 목표

바로우/아라벨라 행동의 결과와 타임라인·VFX·애니메이션을 일치시키고, 기억 보상 확률과 수식 코스트 표시를 데이터 의도대로 수정한다.

## 설계

1. 바로우 후퇴 이동의 방향 전환은 실행용 `FlipBeforeAction`과 분리된 이동 표시 메타데이터로 이동 명령에 표시한다.
2. 거미알은 실행 직전 최종 `GridIndex`를 확정하고 상태 변경과 VFX가 같은 결과를 소비한다.
3. 아라벨라 1페이즈 도주는 안전거리를 만족하는 최소 이동거리부터 선택한다. 경계 차단은 충돌피해 없이 정지한다.
4. 강습 착지에도 그리드 효과를 적용하고, 사망 이후 후속 공격·Idle을 중단한다. 사망 연출 완료 이전에 전투 종료 연출이 덮지 않도록 한다. 1페이즈 전환 예외는 유지한다.
5. 기억 보상은 카드마다 레어도를 먼저 독립 추첨하고 해당 레어도 후보를 선택한다. 없는 레어도는 가용 레어도로 재정규화하고 `BattleRandom`을 사용한다.
6. 기억 코스트 UI는 `ResourceCostFormula`를 정수 값보다 우선 표시한다.
7. 공격+이동은 데미지 확정 직후 이동을 시작하고 피격/카메라 후속 연출과 병행하며 둘이 끝난 뒤 행동 완료로 처리한다.

## 경계

전투 결과는 Command → State Change → Result/Event 구조를 유지한다. UI/VFX/애니메이션은 결과를 계산하지 않으며 안정적인 GridIndex와 ID를 소비한다. 전투 랜덤은 `BattleRandom`만 사용한다.

## 검증

각 원인에 대한 EditMode 회귀 테스트, 런타임/에디터 컴파일, 관련 데이터 및 프리팹 참조 정적 검사를 수행한다. Unity 화면에서만 확인 가능한 연출은 미검증으로 보고한다.
