# 옵션 언어 표시 및 전투 단축키 설정 설계

## 목적

- 옵션 창을 닫았다 다시 열어도 선택한 언어명이 정확히 표시되게 한다.
- 조작 탭에서 전투 단축키 9개를 변경하고 기본값으로 복구할 수 있게 한다.
- 같은 키의 중복 지정을 허용하고, 중복된 모든 옵션 행을 빨간색으로 표시한다.
- 전투 입력과 전투 UI의 키 안내 문자가 현재 설정을 동일하게 사용하게 한다.

## 조사 결과

- `OptionPanelUI.languageValueText`가 언어 선택값 전용 표시가 아니라 `ui.option.header.language` 정적 로컬라이즈가 붙은 텍스트를 참조한다. 옵션 재활성화 시 정적 번역과 동적 언어명 작성이 충돌한다.
- 전투 키는 `BattleKeyboardShortcutBindings`의 상수이며 전투 씬의 `KeyText`는 Q/W/E/R/F/D/C/Z/X가 고정 문자열로 배치되어 있다.
- 옵션 프리팹의 조작 버튼은 있지만 `controlContent` 참조와 `ControlContent` 오브젝트가 없다.

## 선택한 설계

### 공통 단축키 저장소

- 안정적인 동작 ID(`Move`, `Flip`, `Compound`, `Undo`, `Redo`, `Skill01`~`Skill04`)와 기본 `KeyCode`를 한 곳에서 관리한다.
- PlayerPrefs에는 동작 ID별 현재 키를 저장한다.
- 중복 키는 유효하며 하나의 키 입력으로 연결된 모든 동작이 각각 기존 실행 조건을 검사한다.
- 변경 및 기본값 복구 시 이벤트를 발행하여 옵션과 전투 UI가 즉시 갱신되게 한다.

### 옵션 조작 탭

- 옵션 프리팹에 `ControlContent`를 명시적으로 배치하고 9개 행과 전체 기본값 복구 버튼을 둔다.
- 각 행은 로컬라이즈되는 동작명과 현재 키 버튼으로 구성한다.
- 키 버튼 선택 후 다음 키보드 입력으로 값을 변경한다. `Escape`는 변경을 취소한다.
- 동일 키가 둘 이상이면 해당 키를 사용하는 모든 행의 키 표시와 배경을 빨간색으로 표시한다.

### 전투 표시 연동

- 전투 씬과 DebugBattle 씬의 실제 단축키 `KeyText`에 동작 ID를 명시적으로 연결한다.
- 표시 컴포넌트는 공통 저장소의 현재 키를 표시하고 변경 이벤트를 구독한다.
- 타임라인 예약 슬롯의 숫자 1~5는 이번 설정 대상이 아니므로 유지한다.

### 언어 표시 수정

- 언어 제목 로컬라이즈 텍스트와 현재 언어명 텍스트의 소유권을 분리한다.
- 옵션 활성화 시 현재 `SelectedLocale`을 기준으로 언어명을 즉시 동기화하고, 테이블 준비 완료 후 다시 확인한다.
- 기존 언어 저장 방식은 이번 옵션 재오픈 오류의 원인이 아니므로 범위를 확장해 변경하지 않는다.

## 검증

- 단축키 기본값, 저장/로드, 중복 판정, 복구, 표시 문자열을 EditMode 테스트로 검증한다.
- 옵션 프리팹의 조작 콘텐츠/참조와 전투 씬 키 표시 바인딩을 YAML 검사 테스트로 검증한다.
- 언어 선택값 참조가 정적 제목 로컬라이저와 분리됐는지 회귀 테스트로 검증한다.
- `Assembly-CSharp`와 `Assembly-CSharp-Editor`를 컴파일한다.

## 멀티플레이 경계

단축키는 로컬 입력 매핑과 표시만 변경한다. 전투 Command, 상태 변경, 결과/Event 구조와 동기화 데이터에는 영향을 주지 않는다.
