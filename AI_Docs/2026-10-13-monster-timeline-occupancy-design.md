# 몬스터 타임라인 점유칸 설계

## 목표

몬스터 스킬에도 타임라인 점유칸 데이터를 두고, 플레이어와 몬스터가 함께 사용하는 슬롯의 수용량을 실제 점유칸 합계로 판정한다. 평행사변형 슬롯 외형은 이번 범위에서 변경하지 않는다.

## 데이터

- `MonsterSkillData`에 `TimelineEntryCost`를 추가한다.
- `GameData.xlsx`의 `MonsterSkill` 시트와 런타임 CSV에 같은 열을 추가한다.
- 현재 모든 몬스터 스킬 값은 `1`로 설정한다.
- 누락되거나 0 이하인 값은 런타임에서 1칸으로 정규화해 기존 데이터 호환성을 유지한다.

## 동작

- 몬스터 예약 명령은 스킬 데이터의 정규화된 점유칸을 노출한다.
- 타임라인 미리보기는 몬스터 행동도 점유칸만큼 다음 순서를 건너뛴다.
- 슬롯 사용량은 `플레이어 TimelineEntryCost 합계 + 몬스터 TimelineEntryCost 합계`로 계산한다.
- 새 행동은 `현재 점유칸 + 요청 점유칸 <= 5`일 때만 등록한다.
- 몬스터 2칸과 플레이어 2칸이 이미 점유된 상태에서는 추가 2칸 행동을 거부하지만, 실제 1칸 행동은 허용한다.

## 멀티플레이 경계

점유칸은 스킬 ID로 조회되는 정적 데이터이며 Scene Object에 의존하지 않는다. 로컬 예약과 네트워크 스냅샷 복원 경로가 같은 수용량 규칙을 사용하도록 한다.

## 검증

- 몬스터 점유칸 기본값과 정규화 검증
- 혼합 점유 4칸 상태에서 2칸 거부/1칸 허용 검증
- 데이터 로더와 전체 스크립트 컴파일 검증
- Unity 에디터 로그에서 컴파일 오류 확인
