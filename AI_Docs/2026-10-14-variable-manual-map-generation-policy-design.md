# 수동 전투 맵 범용 생성 정책 설계

## 목적

수동 전투 맵을 10개 레이어에 고정하지 않고 템플릿별 길이와 작성된 방 구성을 사용할 수 있게 한다. 데모 템플릿은 기존 0~5 레이어 경로를 복구하고, 기본 배틀 템플릿의 0~9 레이어 랜덤 생성 규칙에는 영향을 주지 않는다.

## 설계

- `ManualBattleMapTemplate`에 `StandardExpedition`, `AuthoredLayout` 생성 정책을 둔다.
- `StandardExpedition`은 기존 0~9 레이어 랜덤 방 구성, 엘리트 수와 경로 제약을 그대로 사용한다.
- `AuthoredLayout`은 직렬화된 시작·중간·보스 레이어를 그대로 사용하고, 연속 레이어 존재 여부와 인접 레이어 연결 가능 여부만 검증한다.
- 보스 레이어는 템플릿별 직렬화 값으로 복원하며 지원 범위는 현재 필드가 존재하는 1~9다.
- 새 정책의 기본값은 `StandardExpedition`으로 정해 기존 기본 템플릿의 직렬화 결과와 런타임 동작을 유지한다.
- 데모 템플릿만 `AuthoredLayout`, 보스 레이어 5를 사용한다.
- 런타임 키에 정책과 보스 레이어를 포함해 서로 다른 템플릿 구성을 구분한다.

## 검증

- 기본 템플릿이 0~9 레이어와 보스 노드 인덱스 33을 유지하는지 검증한다.
- 데모 템플릿이 0~5의 기존 단일 경로를 노출하고 실제 노드 생성에 성공하는지 검증한다.
- 작성형 템플릿도 빈 중간 레이어나 연결 불가능 구조는 거부한다.

## 멀티플레이 영향

생성 결과는 기존과 동일한 `NodeIndex`, `LayerIndex`, `MapId` 기반 데이터다. 네트워크 프레임워크나 동기화 경계는 변경하지 않고, 생성 정책과 레이어 수가 런타임 키에 포함되어 서로 다른 구성의 저장 데이터를 재사용하지 않는다.
