# 데모 맵 첫 고정 노드 제거 설계

## 목표

`Test Manual Battle Map Template Demo`의 첫 번째 고정 맵(`Special`, `Map_25`)을 제거하고, 이후 노드를 한 레이어씩 앞으로 이동한다.

## 변경 후 경로

`Common → Special → Common → Shop(Map_22) → Rest → Boss`

## 데이터 변경

- 보스 레이어를 6에서 5로 변경한다.
- 기존 레이어 1의 `Common`을 시작 노드(레이어 0)로 이동한다.
- 기존 레이어 2~5의 활성 노드를 각각 레이어 1~4로 이동한다.
- 연결은 예약 노드 인덱스 `0 → 1 → 5 → 9 → 13 → 17`을 사용한다.
- 이동 후 사용하지 않는 레이어 5의 슬롯은 비활성화해 오래된 노드 데이터가 남지 않게 한다.

## 검증 기준

- 생성 노드 레이어는 0~5이며 각 레이어에 하나만 존재한다.
- 타입 순서는 `Common, Special, Common, Shop, Rest, Boss`이다.
- 시작 노드에 `Map_25` 오버라이드가 없다.
- 모든 연결이 다음 레이어의 단일 노드를 가리킨다.
- 보스를 제외한 노드는 레이어 간격에 맞춰 한 줄로 배치된다.

## 범위

ScriptableObject 데이터와 해당 에디트 모드 회귀 테스트만 변경한다. 런타임 맵 생성 코드와 전투 로직은 변경하지 않는다.
