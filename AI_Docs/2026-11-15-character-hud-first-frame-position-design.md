# 캐릭터 HUD 첫 프레임 위치 설계

## 목적

캐릭터 HUD가 화면 중앙의 프리팹 기본 위치에 한 프레임 노출된 뒤 캐릭터 머리 위로 이동하는 현상을 제거한다.

## 원인

- `CharacterHUDSlot`은 활성 프리팹으로 생성된다.
- `Show()`는 `UpdateFollowPosition()`이 카메라·타깃 부재 등으로 실패해도 `CanvasGroup.alpha = 1`을 적용한다.
- 이후 `LateUpdate()`에서 위치 계산이 성공하면 HUD가 캐릭터 위치로 이동하므로 순간이동처럼 보일 수 있다.

## 선택 설계

- `Awake()`에서 HUD를 즉시 숨겨 활성 프리팹 생성 시 노출을 차단한다.
- 위치 갱신 메서드는 성공 여부를 반환한다.
- `Show()`는 표시 요청 상태만 기록하고, 위치 계산이 성공한 경우에만 실제 알파와 입력을 활성화한다.
- 위치 계산에 실패하면 숨김 상태로 유지하고 `LateUpdate()`에서 재시도한다.
- 타깃 또는 카메라가 준비된 첫 프레임에 위치를 적용한 뒤 표시한다.

## 제외 범위

- HUD 생성 구조, 표시 조건, 유지 시간, HP·실드 애니메이션은 변경하지 않는다.
- 전투 상태와 캐릭터 위치 계산은 변경하지 않는다.
