# 로컬리제이션 영어 빈 셀 번역 설계

## 목적

`Assets/ExcelSource/Localization.xlsx`의 `Text` 시트에서 한국어 원문이 존재하지만 `English(en)` 셀이 비어 있는 행만 번역한다.

## 적용 기준

- 기존 영어가 입력된 셀은 변경하지 않는다.
- 동일한 한국어 원문에 기존 영어 번역이 있으면 해당 용어를 재사용한다.
- 게임 고유 용어와 캐릭터 이름은 데이터 키에 연결된 기존 번역을 우선한다.
- 숫자 범위, 줄바꿈, 구두점과 문장 역할을 유지한다.
- 키, ID, 한국어 및 다른 언어 열과 워크시트 구조·서식은 변경하지 않는다.

## 검증

- 한국어가 있는 행의 영어 빈 셀이 남지 않았는지 확인한다.
- 수정 대상이 기존 조사 결과인 82개 셀과 일치하는지 확인한다.
- 영어 열 외의 셀 값이 수정 전과 동일한지 비교한다.
- 수정 전후 시트를 렌더링하여 표 구조와 표시 상태를 확인한다.
