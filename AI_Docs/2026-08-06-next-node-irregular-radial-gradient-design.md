# 다음 노드 선택 불규칙 방사형 그라데이션 설계

## 목표

`NextNodeSelectionRoot` 중앙이 가장 어둡고 바깥으로 멀어질수록 불규칙하고 부드럽게 투명해지는 배경을 제공한다.

## 설계

- 검은 연무가 중앙에 세로로 길게 모이고 가장자리는 완전히 투명한 단일 알파 PNG를 사용한다.
- 상단과 하단은 좁거나 뾰족하지 않고 넓고 뭉툭한 곡면으로 부드럽게 사라진다.
- 완전한 원형이나 규칙적인 동심원이 보이지 않도록 가장자리와 내부 농도에 저주파 노이즈를 준다.
- 기존 `GradientBackground` 계층, Ignore Layout, Raycast 비활성 설정은 유지하고 스프라이트와 회전만 교체한다.
- 배경 이미지는 `400x800`으로 배치하며 버튼보다 뒤에 렌더링한다.

## 멀티플레이 경계

시각적 UI 텍스처만 변경하며 맵 상태와 노드 선택에는 영향을 주지 않는다.
