# 배틀 키보드 단축키 복구 설계

## 기준

커밋 `cb8fe4624`의 키 구성을 현재 코드에 다시 적용한다. 이후 추가된 튜토리얼 모달 차단, 플립 병합, 예약 히스토리 및 UI 수정은 유지한다.

## 키 구성

- 이동 `F`, 플립 `D`, 연성제 `C`
- Undo `Z`, Redo `X`
- 스킬 `Q/W/E/R`
- 타임라인 슬롯 이동 `LeftArrow/RightArrow`

## 적용 범위

- `BattleKeyboardShortcutBindings`를 단일 키 정의로 복구한다.
- 일반 전투, 첫 전투 제한, 튜토리얼 프레젠테이션 입력이 같은 정의를 사용한다.
- 신규 튜토리얼 가이드의 이동 허용 키도 `F`를 사용한다.
- 타임라인 컨트롤러가 `Z/X`를 직접 처리하며 기존 Undo/Redo API를 호출한다.

## 멀티플레이 경계

로컬 입력 매핑만 변경하며 Command, 전투 상태, 결과 이벤트 및 네트워크 프로토콜에는 영향이 없다.
