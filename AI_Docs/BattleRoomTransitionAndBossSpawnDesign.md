# 전투방 전환 및 보스 스폰 순서 설계

## 적용 범위

- Common, Elite, Boss 전투방은 `BattlePanelTransition`의 검은 이미지가 걷히기 시작하는 순간 플레이어 걷기 연출을 시작한다.
- 이벤트방과 휴식방 등 비전투방의 입장 흐름은 변경하지 않는다.
- Boss 전투방만 보스 등장 연출이 끝난 뒤 몬스터를 실제 스폰한다.

## 실행 순서

### 모든 전투방

1. 화면이 검게 덮인 시점에 전투방을 열고 플레이어를 입장 시작 위치에 준비한다.
2. `BattlePanelTransition`이 화면을 걷기 시작하기 직전에 별도 콜백을 발생시킨다.
3. 해당 콜백에서 준비된 플레이어 걷기 연출을 시작한다.

### 보스 전투방

1. 플레이어만 먼저 준비하고 몬스터 스폰을 보류한다.
2. 전환이 걷히는 순간 플레이어 걷기를 시작한다.
3. 플레이어 걷기가 끝나면 아라벨라 등장 연출을 재생한다.
4. 등장 연출이 끝난 뒤 보스 몬스터와 HUD를 스폰하고 전투 시작 패시브를 갱신한다.
5. 이후 초기 몬스터 행동 계획과 플레이어 입력을 활성화한다.

## 구조 원칙

- 전환 연출 콜백은 시각 연출 시작 시점만 알리고 전투 결과를 계산하지 않는다.
- 보스 스폰 지연은 `BattleRoomLoader`가 명시적인 상태로 관리한다.
- 전투 입력 및 초기 몬스터 행동 계획은 실제 몬스터 스폰 완료 후에만 진행한다.
- 기존 일반/엘리트 몬스터 데이터 및 스폰 경로는 그대로 사용한다.
