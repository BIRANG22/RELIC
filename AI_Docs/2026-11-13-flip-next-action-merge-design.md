# 플립 다음 행동 결합 설계

## 목적

플립을 독립적인 타임라인 행동이 아니라 같은 캐릭터의 다음 행동에 적용되는 방향 반전 옵션으로 변경한다. 플립은 타임라인 용량을 사용하지 않으며, 결합된 행동의 Undo/Redo와 함께 제거·복원된다.

## 동작

1. 플립 버튼 클릭 또는 드래그 시 대상 슬롯에 0칸 임시 `IsFacingFlipCommand`를 예약한다.
2. 같은 캐릭터가 해당 슬롯에 다음 행동을 예약하면 새 `PlayerReservedCommand`에 `FlipBeforeAction`을 설정하고 임시 플립을 제거한다.
3. 명령의 방향·범위·이동 경로 미리보기는 플립된 방향을 기준으로 계산한다.
4. 타임라인에는 별도 플립 행동을 추가하지 않고 결합된 행동에 플립 하이라이트를 표시한다.
5. Undo/Redo는 결합된 명령 하나를 제거·복원하므로 플립도 함께 처리된다.
6. 다음 행동 없이 턴 종료를 시도하면 임시 플립을 취소하고 경고한다.

## 데이터와 멀티플레이 경계

- 임시 플립은 0칸 예약 명령으로 네트워크 동기화하며, 명령·스냅샷에 `IsFacingFlipCommand`를 보존한다.
- 결합 완료된 `PlayerReservedCommand.FlipBeforeAction`은 명령 스냅샷과 예약 요청에 포함한다.
- 실행과 시뮬레이션은 명령의 안정적인 `CharacterId`, 슬롯 인덱스, 방향 결과를 사용한다.
- 기존 `IsFacingFlipCommand`는 이전 스냅샷과 이미 예약된 독립 플립 호환을 위해 유지한다.

## Undo/Redo

임시 플립 자체는 예약 히스토리에 기록하지 않는다. 다음 행동에 결합된 뒤에는 해당 행동의 기존 히스토리 엔트리 하나만 사용한다. 따라서 `공격(플립 결합) → 공격`에서 Undo 두 번은 공격 두 개를 제거하며, Redo 두 번은 플립 속성을 포함한 두 공격을 복원한다.

## 시각 피드백

- 임시 플립 상태에서는 기존 방향 미리보기를 유지하되 별도 타임라인 칸은 그리지 않는다.
- 결합 직후 해당 타임라인 행동에 예약 피드백을 재생한다.
- 결합된 행동 아이콘은 플립 상태를 식별할 수 있도록 강조 색상을 적용한다.

## 비범위

- 몬스터 행동 플립
- 네트워크 프레임워크 변경
- 타임라인 프리팹 구조 변경
