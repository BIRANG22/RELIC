# TutorialPanel 5페이지 가이드 구현 계획

1. 페이지 인덱스, 키 범위, 일회성 표시 정책을 EditMode 테스트로 고정한다.
2. `TutorialPanelController`에서 이미지·설명·좌우 이동·마지막 페이지 확인 버튼을 제어한다.
3. `TutorialPanel` 프리팹에 컨트롤러와 버튼 컴포넌트를 연결하고 이미지 슬롯 및 `Indicator_01~05/Back` 참조를 각각 5개 노출한다.
4. 페이지 갱신 시 현재 페이지의 Indicator Back만 활성화하고 나머지는 비활성화한다.
5. 신규 튜토리얼 준비 시 일회성 표시 플래그를 설정하고 Battle 씬 진입 시 소비하여 HUD Canvas에 프리팹을 생성한다.
6. 로컬라이제이션 키 5개를 코드, 엑셀, Shared Data, 각 언어 테이블에 빈 값으로 등록한다.
7. 런타임·에디터 컴파일, 키 중복, 프리팹·씬 참조를 검증한다.
