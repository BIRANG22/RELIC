# Battle Character Move Selection Toggle

## 목적

- 캐릭터를 선택했을 때 이동 스킬과 이동 범위가 자동 선택되지 않게 한다.
- 이미 선택 중인 캐릭터의 이동 버튼을 다시 누르면 이동 선택과 예약 미리보기를 취소한다.

## 변경 범위

- `BattleTimelineController`에서 캐릭터 패널 표시 완료를 기다린 뒤 이동 스킬을 자동 선택하던 요청/코루틴을 제거한다.
- `BattleTimelineController`에 현재 캐릭터의 동일 이동 스킬 선택 여부를 판별하고, 선택 또는 취소를 수행하는 단일 진입점을 둔다.
- `BattleCharacterPanelUI`의 이동 버튼만 이 진입점을 사용한다.

## 보존 사항

- 타임라인 슬롯 자동 선택, 실제 스킬 예약, 이동 경로 계산, 전투 명령과 결과 계산은 변경하지 않는다.
- 다른 스킬 버튼은 기존 선택 동작을 유지한다.
- 취소는 기존 `CancelSkillReservationPreviewFromSkillList` 정리 경로를 사용한다.

## 검증

- 캐릭터 선택 후 선택 스킬이 비어 있는지 확인한다.
- 동일 캐릭터·이동 스킬이 선택 중일 때 토글 호출이 선택과 미리보기를 취소하는지 확인한다.
