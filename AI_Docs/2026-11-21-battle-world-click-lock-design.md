# 전투 실행 중 월드 클릭 차단 설계

## 문제

전투 행동 실행 중에도 몬스터 월드 오브젝트의 클릭 진입점이 호출될 수 있다. 몬스터 정보 패널은 전투 카메라와 같은 이동 코루틴을 사용하므로, 실행 중 패널을 반복해서 열고 닫으면 행동 연출의 카메라 코루틴을 중단할 수 있다.

현재 몬스터 클릭 허용 조건은 튜토리얼 허용값과 `BattleTurnExecutor.CanAcceptPlayerInput`을 OR로 결합한다. 일반 전투에서는 튜토리얼 허용값이 참이므로 실행 중 입력 차단을 우회한다.

## 설계

1. `BattleWorldClickGate`를 전투방 월드 클릭의 공통 정책으로 둔다.
2. `BattleTurnExecutor.IsExecuting`이 참이면 모든 전투방 월드 클릭을 차단한다.
3. 몬스터 정보 패널은 공통 정책에 더해 `CanAcceptPlayerInput`과 튜토리얼 몬스터 클릭 조건을 모두 만족해야 한다.
4. 캐릭터, 몬스터, 그리드 셀, 스킬 대상 그리드의 클릭 진입점에서 공통 정책을 검사한다.
5. `OnMouseEnter`, `OnMouseExit` 등 호버 경로에는 공통 정책을 적용하지 않는다.

## 경계

- UI 버튼과 ESC 입력은 월드 클릭 정책의 대상이 아니다.
- 시작방과 이벤트방 오브젝트는 `BattleTurnExecutor`의 전투 행동 실행 대상이 아니므로 변경하지 않는다.
- 전투 결과와 상태 계산은 변경하지 않는다. 입력이 기존 Command/예약 경로에 도달하기 전에 차단한다.

## 검증

- 실행 중 월드 클릭 차단, 예약 입력 단계 허용, 실행기 부재 시 비전투 오브젝트 허용을 순수 정책 테스트로 검증한다.
- 몬스터 정보 클릭은 튜토리얼 허용만으로 실행기 입력 차단을 우회할 수 없음을 검증한다.
- 프로젝트 C# 컴파일과 변경 파일 정적 검사를 수행한다.
