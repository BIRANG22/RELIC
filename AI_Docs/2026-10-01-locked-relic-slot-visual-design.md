# 침식 유물 슬롯 잠금 표시 설계

## 조사 결과

- `InventoryPanel.prefab`의 편집 슬롯과 별개로 전투 HUD는 `Artifact01~06`에서 패시브 유물 인덱스 1~6을 표시한다.
- 실제 잠금 대상은 전투 HUD의 `Artifact06`, 즉 런타임 유물 인덱스 6이다.
- 전투 UI에 이미 `CobwebUI` 스프라이트가 잠금 오버레이 용도로 사용되고 있다.

## 설계

- 전투 규칙 계층은 `EquippedRelicIds[6]`을 마지막 슬롯으로 판정하며 장착 거부와 전투 시작 시 해제를 동일한 판정 함수로 처리한다.
- `BattleCharacterPanelUI`는 상태를 읽어 파티 HUD와 선택 캐릭터 상세 패널의 `Artifact06`에 `CobwebUI`를 표시한다.
- 잠금 여부를 HUD 갱신 해시에 포함하여 데이터 초기화 이후에도 표시가 즉시 갱신되게 한다.

## 피해 증가 보정 경계

- 몬스터 예약 명령과 네트워크 스냅샷에는 보정 전 기본 피해를 저장한다.
- 침식 피해 증가는 실제 피해값을 조회하는 전투 계산 경계에서 정확히 한 번 적용한다.
- 저장 복원이나 네트워크 동기화가 예약 피해를 다시 주입해도 침식 보정이 누락되지 않는다.

## 멀티플레이 경계

- 잠금 판정은 ID/슬롯 인덱스 기반 전투 규칙에 유지한다.
- UI는 상태를 변경하지 않고 잠금 결과를 표시하며, 실제 장착 차단은 `RelicEquipService`에서 수행한다.
