# 데모 맵 및 시작 파티 변경

## 목적

데모 전투의 스페셜 노드와 상점 노드 사이에 일반 전투 노드를 하나 추가하고, 데모 시작 파티의 이네스를 헤이즈로 교체한다.

## 맵 구성

변경 후 데모 맵은 다음 단일 경로를 사용한다.

`시작 이벤트 → 일반 전투 → 스페셜 → 일반 전투 → 상점 → 휴식 → 보스`

추가되는 일반 전투 노드는 `Common` 타입이며 `MapIdOverride`를 비워 일반 전투맵 선택 규칙을 그대로 사용한다. 상점, 휴식 및 보스 레이어는 한 단계씩 뒤로 이동하고 모든 노드는 기존과 동일하게 중앙 정렬한다.

## 시작 파티

데모 전용 시작 파티를 `Char_01`, `Char_02`, `Char_03`으로 구성한다. 일반 게임의 기본 파티 설정은 변경하지 않는다.

## 검증

- 활성 레이어가 0부터 6까지 단일 경로로 연결되는지 확인한다.
- 노드 타입 순서와 추가된 Common 노드의 빈 맵 오버라이드를 확인한다.
- 중간 노드의 중앙 커스텀 위치를 확인한다.
- 데모 파티의 세 번째 캐릭터가 `Char_03`인지 확인한다.
