# 타임라인 소유자 아이콘 큐 설계

## 목표

한 타임라인 슬롯의 실행 행동을 최대 5개의 소유자 아이콘으로 표시한다. 아이콘은 행동 순서대로 겹쳐 보이고, 실제 행동 실행 시 해당 아이콘이 아래에서 위로 투명해지며 제거된 뒤 다음 아이콘이 선두 상태가 된다.

## 표시 규칙

- 슬롯 프리팹의 고정 아이콘 이름은 `OwnerIcon01`부터 `OwnerIcon05`까지 사용한다.
- 행동의 실제 `OrderIndex` 오름차순으로 아이콘 1~5에 연결한다. 같은 소유자의 행동이 연속되면 하나의 아이콘 그룹으로 묶고, 다른 소유자 행동 뒤에 다시 등장하면 새 아이콘으로 표시한다.
- 아이콘의 X 간격은 10이다. `OwnerIcon01`이 가장 앞에 그려지고 숫자가 커질수록 뒤에 그려진다.
- 선두 아이콘 알파는 1, 대기 아이콘 알파는 기본 0.5로 표시한다.
- 한 슬롯의 표시 한도는 전투 슬롯 용량과 같은 5개다.

## 실행 연출

- 전투 실행부가 이미 확정한 `slotIndex`와 `orderIndex` 목록을 UI에 전달한다.
- UI는 전달된 순서에 해당하는 아이콘만 아래에서 위로 진행되는 소프트 그라데이션으로 제거한다. 연속 행동 그룹은 마지막 행동 실행 시 제거한다.
- 제거가 끝나면 남은 아이콘을 앞으로 당기고 새 선두 아이콘 알파를 1로 복원한다.
- 같은 실행 배치에 여러 행동이 포함되면 실제 전투의 병렬 실행 의미를 유지하도록 해당 아이콘들을 함께 제거한다.
- UI 애니메이션은 전투 판정이나 명령 상태를 변경하지 않는다.

## 구현 경계

- `BattleTimelineGroupUI`는 현재 슬롯의 표시 엔트리와 아이콘 큐를 소유한다.
- `BattleTimelineBarUI`는 슬롯 인덱스로 그룹에 실행 연출을 전달한다.
- `BattleTimelineController.PlayTimelineIconsAfterActionRoutine`은 기존 스킬 아이콘 연출과 같은 시점에 소유자 아이콘 연출을 시작한다.
- 세로 그라데이션은 UI 전용 셰이더의 진행 값으로 표현하며, 각 아이콘은 독립 머티리얼 인스턴스를 사용한다.
- 프리팹에서 조정한 아이콘 부모와 01/02 위치는 런타임 코드가 덮어쓰지 않는다. 호환 생성되는 03~05만 01/02 간격을 이어받는다.

## 멀티플레이 영향

명령, 상태, 스냅샷, 실행 순서는 바꾸지 않는다. 호스트가 확정한 실행 배치의 안정적인 슬롯/순서 인덱스를 UI가 소비하므로 멀티플레이 전투 결과에는 영향이 없다.

## 검증 기준

- 최대 5개 엔트리가 순서대로 아이콘에 연결된다.
- X 위치가 10 간격이고 `OwnerIcon01`이 최상위 렌더 순서다.
- 선두만 완전 불투명이고 나머지는 반투명이다.
- 실행된 순서만 제거되고 남은 아이콘이 당겨지며 새 선두가 불투명해진다.
- 런타임 및 에디터 어셈블리가 컴파일된다.
