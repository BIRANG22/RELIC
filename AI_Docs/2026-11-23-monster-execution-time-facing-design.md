# 몬스터 실행 시점 방향 전환 설계

## 의도

몬스터가 예약된 첫 행동 방향을 턴 시작 전에 미리 바라보는 동작을 제거한다. 첫 행동을 포함한 각 행동의 방향 전환은 명령에 기록하고 실제 행동 실행 직전에만 전투 상태와 외형에 적용한다.

## 목표

- 일반 행동 예약 완료 후 몬스터의 현재 방향을 변경하지 않는다.
- 첫 행동도 현재 방향과 행동 방향이 다르면 `FlipBeforeAction`을 유지한다.
- 실제 행동 실행 직전에 기존 `BattleActionRunner.ApplyFlipBeforeMonsterAction` 경로로 방향을 변경한다.
- 후속 행동의 방향은 앞선 명령 실행 이후의 예상 방향을 기준으로 결정한다.
- 녹턴 포털처럼 특수 연출 중 특정 방향을 바라보는 동작은 유지한다.

## 비목표

- 몬스터 AI의 대상·범위·이동 경로 결정을 변경하지 않는다.
- 플레이어 방향 전환 규칙을 변경하지 않는다.
- 특수 연출 자체의 방향 연출을 제거하지 않는다.

## 선택한 접근

일반 예약 방향 적용과 특수 연출 방향 적용을 분리한다. 예약 완료 및 턴 시작 상태효과 처리에서 `ApplyFirstReservedActionFacing` 계열 호출을 제거하고, 명령 계획의 `AssignMonsterMergedFlips`는 유지한다. 특수 연출은 필요한 방향을 임시 적용한 뒤 연출 전 방향으로 복원한다.

첫 행동 방향을 적용한 뒤 `FlipBeforeAction`을 지우는 기존 메서드는 일반 흐름에서 사용하지 않는다. 실행 시점에는 이미 존재하는 `BattleActionRunner`가 `FlipBeforeAction`을 소비하지 않고 방향 상태와 `BattleUnitFacing`을 함께 변경한다.

## 특수 연출 규칙

- 녹턴 포털: 연출 직전 방향을 저장하고 포털 방향을 바라본 뒤 원래 방향으로 복원한다.
- 아라벨라 거미줄: 특수 행동 애니메이션은 유지하지만 완료 후 첫 예약 행동 방향으로 정렬하지 않는다.
- 특수 연출 종료가 일반 첫 행동 방향을 미리 적용하는 통로가 되지 않게 한다.

## 멀티플레이 경계

`MonsterReservedCommand.FlipBeforeAction`은 기존 네트워크 스냅샷에 포함된다. 방향 판정은 계획 명령에 결정론적으로 기록하고 실제 실행 상태 변경은 기존 러너에서 수행하므로 새로운 동기화 모델은 추가하지 않는다.

## 검증 기준

- 첫 몬스터 행동도 반대 방향이면 `FlipBeforeAction`이 참이다.
- 예약 직후 몬스터 런타임 방향은 바뀌지 않는다.
- 포털 특수 연출은 포털 방향을 바라보며 종료 후 원래 방향으로 돌아온다.
- 실제 명령 실행 직전에만 방향 상태가 바뀐다.
- 런타임·에디터 어셈블리가 오류 없이 컴파일된다.
