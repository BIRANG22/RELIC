# 배틀 맵 최근 노드 정보 유지 및 단일 라인 복구 설계

## 노드 정보

- 지도 패널이 열릴 때 `CurrentNodeIndex`에 해당하는 노드를 정보창에 표시한다.
- 현재 노드를 찾지 못하면 시작 노드를 대신 표시한다.
- 노드를 호버하면 해당 노드 정보로 교체한다.
- 호버 종료 시 정보창을 초기화하지 않아 가장 최근에 호버한 정보가 유지된다.
- 지도 패널을 닫았다 다시 열면 그 시점의 현재 노드 정보로 다시 초기화한다.

## 라인

- `line_horizontal` 스프라이트 하나만 사용한다.
- 라인의 중심은 두 노드 좌표의 중간으로 둔다.
- 길이는 두 노드 거리에서 양끝 `endpointInset`을 뺀 값으로 계산한다.
- 라인 RectTransform을 두 노드 방향 각도로 회전한다.
- 방향별 스프라이트와 수평 플립 판정은 제거한다.

## 검증

- 현재 노드 탐색은 기존 `MapRuntimeProgressUtility.FindCurrentNode` 동작을 사용한다.
- 라인의 길이·중심·회전값을 EditMode 테스트로 검증한다.
- LinePrefab이 `line_horizontal`만 참조하는지 정적으로 확인한다.

## 멀티플레이 영향

표시 UI와 라인 연출만 변경한다. 맵 진행 상태와 노드 선택 결과에는 영향을 주지 않는다.
