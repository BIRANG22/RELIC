# 타임라인 플립 라인 및 도움말 키 변경 설계

## 목적

- 플립이 행동에 병합됐음을 행동 테두리 색 변경이 아니라 `TimelineSlot.prefab`의 `FipLine/image`로 표시한다.
- 플레이어 플립 라인은 파랑, 몬스터 플립 라인은 빨강으로 표시한다.
- 디버그 도움말 패널 토글 키를 `` ` ``에서 `\`로 옮긴다.

## 설계

- `BattleTimelineGroupUI`는 활성 행동 크기 루트 내부의 `FipLine` 오브젝트 자체 `Image` 컴포넌트를 사용한다. 자식 `Image` 색상은 변경하지 않는다.
- `HasMergedFacingFlip`인 엔트리만 `FipLine`을 활성화하고, 소유자가 플레이어면 `playerReservedColor`, 몬스터면 `enemyReservedColor`를 적용한다.
- 기존 행동 테두리는 플립 여부와 무관하게 소유자 색상을 유지한다.
- 슬롯 초기화, 크기 루트 전환, 빈 슬롯 표시 시 `FipLine`을 반드시 비활성화한다.
- 새 UI 오브젝트는 런타임 생성하지 않고 기존 프리팹 배치를 재사용한다.
- `DebugShortcutHelpPanel` 기본 키와 `Bootstrap.unity`의 직렬화 값을 모두 `KeyCode.Backslash`로 맞춘다.

## 고려한 방식

- 선택: 현재 활성 크기 루트에서 기존 `FipLine/image`를 찾아 제어한다. 크기별 변형을 이미 동적으로 선택하는 현 구조와 일치한다.
- 제외: 모든 크기 변형의 참조 배열을 새로 직렬화한다. 프리팹 변형 수가 많아 누락과 순서 불일치 위험이 크다.
- 제외: 런타임에 플립 라인을 생성한다. 아트가 배치한 프리팹 구조를 우회한다.

## 비범위

- 플립 예약·실행 판정 자체는 변경하지 않는다.
- 플레이어/몬스터 예약 기본 색상 값은 변경하지 않는다.
