# 월드 유닛 HUD 안전 표시 구현 계획

1. `HUDSlot`의 생성 직후 숨김, 위치 미준비 시 표시 차단, 비활성화 시 강제 숨김을 검증하는 EditMode 테스트를 먼저 작성한다.
2. 위치 갱신을 성공 여부를 반환하는 함수로 변경하고 표시 요청 상태와 실제 가시성을 분리한다.
3. 지연 활성화된 콜라이더의 머리 오프셋을 재계산한다.
4. 아군·적군 HUD 제거 및 런타임 몬스터 해제 경로에서 즉시 숨김과 소유권 정리를 수행한다.
5. 관련 테스트 어셈블리와 런타임 어셈블리를 컴파일하고 변경 범위를 검토한다.

## 검증 초점

- 아군·적군 공통 프리팹 생성 직후 alpha 0
- 타깃 또는 카메라가 없는 `Show`에서 alpha 0
- 비활성화 후 alpha 0
- 유효 위치가 준비된 뒤에만 표시
- 제거·재생성 프레임에 이전 HUD가 남지 않음
