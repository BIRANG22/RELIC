# 가시(E_Ward) 반사 피해 설계

## 문제

`E_Ward`는 상태 효과로 정상 부여되지만, 직접 공격 피해를 받은 뒤 공격자에게 피해를 돌려주는 실행 경로가 없다. 데이터 설명과 실제 전투 결과가 일치하지 않는다.

## 목표 동작

- `E_Ward` 보유자가 직접 공격으로 실제 피해를 받으면 공격자에게 현재 가시 스택만큼 피해를 준다.
- 방어막으로 받은 피해도 피해를 받은 것으로 간주한다.
- 피해가 0이면 발동하지 않는다.
- 지속 피해, 그리드 피해, 자해, 가시 반사 피해에는 발동하지 않는다.
- 가시 반사 피해는 다시 가시를 발동시키지 않는다.
- 공격자가 사망하면 기존 플레이어 전투불능/몬스터 사망 처리 흐름을 사용한다.
- 반사 피해로 공격자가 사망하면 현재 다단 공격과 후속 피해 효과를 즉시 중단한다.

## 구조

직접 공격을 실제 피해로 변환하는 `StrikeEffect`와 `PierceEffect`가 피해량을 확정한 뒤 `BattleWardReactionService`에 `BattleEffectContext`와 실제 피해량을 전달한다. 서비스는 피격자의 `E_Ward` 스택을 읽고, 컨텍스트에 기록된 공격자에게 기존 `BattleEffectUtility` 피해 API로 반사 피해를 적용한다.

반사 여부와 반사량 계산은 런타임 오브젝트와 분리된 순수 함수로 두어 EditMode 테스트에서 검증한다. UI/VFX는 결과 계산에 관여하지 않고 기존 피해 표시 경로만 재사용한다.

## 멀티플레이 경계

가시 반응의 입력은 피격자 상태, 실제 피해량, 공격자 런타임 데이터이며 결과는 공격자 체력 변경이다. 향후 네트워크 Command 처리 시 직접 공격 결과에 파생된 상태 변경/이벤트로 직렬화할 수 있도록 Scene 탐색이나 프레젠테이션 완료 여부에 의존하지 않는다.
