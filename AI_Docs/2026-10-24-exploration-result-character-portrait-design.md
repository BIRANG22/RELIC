# 탐사 정산 캐릭터 이미지 및 정보 아이콘 설계

## 의도

탐사 정산 캐릭터 카드의 인물 이미지를 현재보다 약 2배 크게 보여주되 기존 `250 x 90` 이미지 박스 밖으로 넘는 부분은 잘라낸다. 정보 아이콘은 이미지 박스 왼쪽 아래 모서리의 원형 버튼으로 표시하고, 호버·클릭 동작은 유지하면서 정보창의 현재 표시 위치는 변경하지 않는다.

## 선택한 방식

- 각 캐릭터 카드에 `PortraitViewport`를 두고 `RectMask2D`로 `250 x 90` 영역을 자른다.
- 기존 `Portrait`를 Viewport의 자식으로 옮기고 로컬 배율을 `2 x 2`로 설정한다.
- 기존 느낌표 이미지는 `40 x 40` 원형 배경의 자식으로 두고 이미지 박스 왼쪽 아래에 배치한다.
- 아이콘의 실제 호버·클릭 영역은 원형 버튼 크기만 사용한다.
- 기존 정보창 위치 계산용 RectTransform은 투명한 `StatisticsOverlayAnchor`로 분리해 기존 위치에 유지한다.

## 대안

- 기존 `250 x 32` 정보 아이콘 RectTransform 안에서 시각 요소만 이동하는 방식은 변경량이 적지만 아이콘 밖에서도 호버가 반응하므로 사용하지 않는다.
- Portrait 자체에 Mask를 붙이는 방식은 마스크와 확대 대상이 동일해 계층 및 클리핑 제어가 불명확하므로 별도 Viewport를 사용한다.

## 제약

- 정보창 내용과 표시 위치 계산 방식은 유지한다.
- 캐릭터 이미지 확대와 정보 아이콘은 세 캐릭터 카드에 동일하게 적용한다.
- 전투 상태 및 정산 데이터 계산은 변경하지 않는다.

## 검증

- 세 카드 모두 Viewport, RectMask2D, 2배 Portrait, 원형 정보 버튼, 별도 정보창 기준점을 갖는지 EditMode 회귀 테스트로 확인한다.
- 런타임 및 에디터 어셈블리를 컴파일한다.
- 실제 이미지 크롭과 원형 버튼의 시각적 결과는 Unity 에디터에서 확인한다.
