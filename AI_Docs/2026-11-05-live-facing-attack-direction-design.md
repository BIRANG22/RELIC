# 실행 직전 방향 기반 공격 설계

## 규칙

- 플레이어와 몬스터의 방향 기반 공격은 행동 시작 직전 `RuntimeData.Direction`을 실행 방향으로 확정한다.
- 공격, 이동 후 공격, 공격 후 이동, 돌진 공격과 해당 효과 컨텍스트는 한 행동 동안 같은 실행 방향을 사용한다.
- 예약 방향은 미리보기와 예약 시뮬레이션에만 사용한다.
- 몬스터의 명시적 지정 그리드 공격은 `HasExplicitRangeResult`의 범위와 대상을 유지한다.
- 실행 방향은 Scene Transform이 아니라 전투 RuntimeData에서 읽는다.

## 흐름

`Reserved Command -> 실행 직전 RuntimeData.Direction 확정 -> 범위/이동/효과 결과 -> 연출`

몬스터 지정 그리드 공격은 방향 확정과 무관하게 예약된 그리드 결과를 사용한다.
