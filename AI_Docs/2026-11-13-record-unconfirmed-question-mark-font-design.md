# 기록서 미발견 물음표 폰트 수정 설계

## 의도

기록서의 미발견 슬롯은 `?`를 표시해야 하지만, 현재 `DungGeunMo Legacy SDF`의 물음표 글리프 아틀라스 좌표가 잘못되어 `ㅂ`처럼 보인다.

## 목표

- `RecordIconSlot`의 `Unconfirmed` 텍스트가 정상적인 `?` 글리프를 사용한다.
- 기록서 외 UI와 공용 폰트 아틀라스는 변경하지 않는다.
- 프리팹의 문자 값 `?`와 안전한 폰트 참조를 회귀 검사한다.

## 비목표

- 손상된 `DungGeunMo Legacy SDF` 전체 아틀라스를 재생성하지 않는다.
- 기록서 슬롯의 레이아웃, 색상, 공개 조건은 변경하지 않는다.

## 검토한 접근

1. `DungGeunMo Legacy SDF` 아틀라스 전체 복구: 다른 UI에 미치는 범위가 크고 Unity 폰트 에셋 재생성이 필요해 제외한다.
2. `Unconfirmed`만 정상 `DungGeunMo SDF`로 교체: 동일 원본 TTF의 정상 물음표 글리프를 사용하며 영향 범위가 가장 작아 채택한다.
3. 물음표를 이미지로 교체: 별도 리소스와 UI 구조 변경이 필요해 제외한다.

## 설계

`RecordIconSlot.prefab`의 `Unconfirmed` TMP 컴포넌트가 `DungGeunMo SDF`와 해당 기본 머티리얼을 참조하도록 변경한다. EditMode 테스트는 실제 프리팹을 로드해 `Unconfirmed`의 텍스트가 `?`인지, 폰트가 안전한 에셋인지, 해당 폰트가 `?` 문자를 제공하는지 확인한다.

## 멀티플레이 경계

기록서 표시용 프리팹 참조만 변경하므로 전투 명령, 상태, 결과 이벤트 및 동기화 데이터에 영향이 없다.
