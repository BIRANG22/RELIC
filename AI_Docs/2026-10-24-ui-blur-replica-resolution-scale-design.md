# UI 블러 복제 해상도 스케일 수정 설계

## 의도

전투 이벤트 선택지가 표시된 상태에서 ESC 메뉴를 열면, 기준 해상도 이외에서 블러에 포함된 선택지 전체가 확대되어 보이는 문제를 수정한다.

## 원인

`UIBlurReplicaSource`는 루트 UI의 월드 모서리를 화면 좌표로 변환한 뒤 블러 Canvas 로컬 좌표로 다시 계산한다. 이 계산 결과에는 원본 Canvas의 해상도 배율이 이미 포함되어 있지만, 루트 복제본에 원본 `localScale`을 다시 적용하여 배율이 중복된다.

## 설계

- 화면 좌표로 크기와 위치를 재구성하는 루트 복제본은 `localScale = Vector3.one`을 사용한다.
- 자식 복제본은 기존과 같이 원본 로컬 스케일을 유지한다.
- 메뉴, 이벤트 선택지 및 전투 상태 로직은 변경하지 않는다.

## 검토한 대안

- 이벤트 선택지 Canvas만 블러 대상에서 제외: 확대는 사라지지만 메뉴 블러에서 선택지가 누락되므로 제외한다.
- 해상도별 역배율을 별도 계산: 이미 화면→로컬 좌표 변환이 정규화를 담당하므로 중복 계산이 되고 복잡도가 증가한다.
- 루트 복제본만 단위 스케일 사용: 좌표 변환 계약과 일치하고 다른 블러 대상에도 동일하게 적용되므로 채택한다.

## 검증

- 원본 루트 스케일이 1이 아니어도 블러 복제 루트는 단위 스케일인지 EditMode 테스트로 검증한다.
- 자식의 의도된 로컬 스케일은 유지되는지 함께 검증한다.
- C# 프로젝트 컴파일로 회귀를 확인한다.
