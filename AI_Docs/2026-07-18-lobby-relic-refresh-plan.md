# Lobby Relic Refresh Implementation Plan

**Goal:** 구매된 유물을 유지하며 나머지 로비 유물 오퍼를 유료로 재추첨한다.

**Architecture:** 순수 서비스가 가격·실패·오퍼 변경을 계산하고 `LobbyRelicShopPresenter`가 버튼과 HUD만 갱신한다.

### Task 1: 가격 및 재추첨 서비스

- [ ] 가격 50/75/100 테스트를 작성한다.
- [ ] 구매 슬롯 유지 및 미구매 슬롯 변경 테스트를 작성한다.
- [ ] 전부 구매 시 실패 테스트를 작성한다.
- [ ] 최소 서비스 구현 후 테스트 컴파일을 확인한다.

### Task 2: 새로고침 버튼 UI

- [ ] `icon_cost_recharge` 이미지와 가격 텍스트를 가진 버튼을 생성한다.
- [ ] 세 번째 유물 다음 월드 간격에 버튼을 배치한다.
- [ ] 구매·새로고침 후 가격과 활성 상태를 갱신한다.

### Task 3: 검증

- [ ] C# 컴파일을 확인한다.
- [ ] 씬의 아이콘 참조와 새 런타임 필드를 확인한다.
- [ ] 배틀 데이터 및 자동 저장 호출이 추가되지 않았는지 검사한다.
