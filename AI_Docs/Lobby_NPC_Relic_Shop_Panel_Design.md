# 거점 NPC 유물 상점 패널 설계

## 목표

Lobby 배경에 항상 노출되던 유물 상품과 리롤 UI를 제거하고, `Character/npc` 오브젝트를 클릭했을 때만 중앙 상점 패널을 연다. 패널에서는 액티브와 패시브를 포함한 전체 유물 중 3개를 블루더스티움으로 구매하고 리롤할 수 있다.

## 화면과 입력

- Lobby 시작 시 상점 패널은 닫혀 있다.
- `Character/npc` SpriteRenderer 오브젝트에 2D 클릭 콜라이더와 NPC 클릭 컴포넌트를 연결한다.
- NPC를 클릭하면 Lobby Canvas 중앙의 어두운 반투명 패널이 열린다.
- 패널에는 유물 상품 3개를 가로로 표시한다.
- 각 상품은 유물 아이콘과 가격 텍스트를 표시하며, 클릭하면 구매한다.
- 구매된 상품은 구매 완료 상태로 비활성화한다.
- 패널 하단에는 리롤 버튼과 현재 리롤 가격을 표시한다.
- 패널 우측 상단에는 `X` 닫기 버튼을 둔다.
- 별도 신규 이미지 없이 기본 UI Image와 기존 유물/리롤 아이콘을 사용한다.

## 데이터와 로직

- 기존 `LobbyRuntimeData.RelicOfferIds`, `RelicOfferSeed`, `RelicRefreshCount`, `OwnedRelicIds`, `BlueDustium`을 그대로 사용한다.
- 기존 구매와 리롤 서비스의 시드 기반 흐름을 유지한다.
- 상품 후보 필터에서 액티브 전용 제한을 제거하고 가격을 계산할 수 있는 모든 액티브/패시브 유물을 허용한다.
- 구매 서비스에서도 패시브 유물을 거부하지 않도록 변경한다.
- UI 클릭은 서비스 명령을 호출하고 결과에 따라 화면만 갱신한다.
- 패널을 닫아도 현재 상품 목록은 유지하며, 다시 열면 같은 상품을 표시한다.

## 구조

- `LobbyRelicShopPresenter`: 월드 앵커 버튼 생성을 제거하고 패널 내부 상품/리롤 UI를 관리한다.
- `LobbyRelicShopNpcInteraction`: NPC 클릭을 받아 Presenter의 `Open()`을 호출한다.
- Lobby 씬: 상점 패널, 상품 컨테이너, 닫기 버튼, NPC 콜라이더와 참조를 직렬화한다.
- 기존 구매/리롤 서비스는 UI와 분리된 상태를 유지한다.

## 오류 처리와 검증

- 데이터 매니저, DB 또는 런타임이 없으면 빈 상품 상태를 표시하고 구매하지 않는다.
- 잔액 부족, 이미 보유, 후보 부족 시 데이터는 변경하지 않는다.
- 액티브/패시브 혼합 후보, 구매 차감, 리롤 차감과 시드 갱신을 EditMode 테스트로 검증한다.
- Unity 에디터에서 NPC 클릭, 패널 열기/닫기, 3개 표시, 구매, 리롤을 수동 확인한다.
