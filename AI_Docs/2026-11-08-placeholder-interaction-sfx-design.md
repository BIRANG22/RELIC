# 임시 상호작용 SFX 설계

## 의도

아직 최종 사운드가 준비되지 않은 UI·연출 지점에 명확한 교체용 임시 사운드를 연결해 누락 여부를 플레이 중 즉시 식별한다. 현재는 모든 지점이 `SFX_TEMP_WRONG_SOUND.mp3`를 사용하되, 이후 각 사운드를 독립적으로 교체할 수 있어야 한다.

## 범위

- 튜토리얼 텍스트 다음 문장 진행
- 이동·플립 버튼 클릭
- 전투 리셋·스킬 취소
- 캐릭터 편성 HUD 버튼 및 월드 오브젝트 전환
- 전투 타임라인 마커 클릭
- 룬 장착 드래그앤드롭 성공
- 스킬 변경 성공
- 스킬 재료 합성 성공
- 스킬 재료 제거 성공
- 캐릭터 편성 제거 성공
- 그리드 선택을 포함한 드래그앤드롭 진행 성공
- 유물·연성제 장착 성공
- 탐사 보고 숫자·게이지 카운트업

로비 편성창의 유물·연성제 슬롯은 기존 클릭 사운드를 제거하고 실제 장착 성공 시점에만 재생한다. 클릭과 드래그앤드롭은 같은 장착 결과 피드백으로 취급한다.

## 권장 구조

`Assets/DB/SoundDatabase.asset`에 동작별 문자열 SFX ID를 각각 등록하고 모든 항목의 클립은 동일한 임시 MP3를 참조한다. 코드 기본값은 `AudioIds.Sfx` 상수를 사용하고, 조정 가능한 호출부는 `[SoundId(SoundCategory.Sfx)]` 직렬화 필드와 볼륨 필드를 둔다. 사운드는 입력 시작이 아니라 실제 상태 변경 또는 선택 확정 이후에 한 번만 재생한다.

## 고려한 방식

1. **동작별 ID, 공용 임시 클립 — 채택.** 향후 DB에서 각 항목만 독립 교체할 수 있고 코드 변경이 최소화된다.
2. 단일 공용 ID — 구현은 작지만 어느 호출부가 어떤 최종 사운드로 갈지 분리하기 어렵다.
3. 각 컴포넌트가 `AudioClip` 직접 참조 — 기존 ID 기반 오디오 정책과 인스펙터 드롭다운을 우회하므로 제외한다.

## 제약 및 비목표

- 사운드는 UI/연출 결과만 재생하며 전투 결과 계산이나 상태 변경을 담당하지 않는다.
- 실패한 장착·합성·변경·제거, 취소된 드래그에는 재생하지 않는다.
- 기존에 같은 의미의 사운드 호출이 있으면 새 호출을 겹치지 않고 ID만 교체한다.
- 최종 음향 밸런싱과 실제 최종 사운드 선정은 이번 범위가 아니다.
- Unity 에디터 직접 제어 및 batchmode 테스트는 수행하지 않는다.

## 멀티플레이 경계

전투·로비의 권위 상태 및 Command/State Change 흐름은 변경하지 않는다. 사운드는 기존 성공 결과를 관찰한 로컬 프레젠테이션 계층에서만 재생하므로 동기화 데이터와 랜덤 결과에 영향이 없다.
