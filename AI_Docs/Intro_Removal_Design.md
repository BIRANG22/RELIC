# 타이틀·스토리 인트로 제거 설계

## 제거 범위

- 새 게임 시작 전 `IntroSequenceController` 기반 스토리 인트로
- `PressAnyKeyIntro` 기반 타이틀 입력 대기 및 로고 시작 연출
- 옵션의 인트로 토글·다시보기, Intro PlayerPrefs, 디버그 초기화 연동
- Bootstrap 씬과 Option 프리팹의 인트로 전용 오브젝트
- 인트로 전용 코드, 이미지, 애니메이션, 머티리얼, 셰이더, 로컬라이제이션 키

## 유지 범위

- `IBattleRoomIntroSequence` 기반 보스 등장 및 방 로딩 연출
- `BattleMapIntroText` 기반 전투 시작·행동 예약·전투 종료 안내
- 전투 튜토리얼 및 튜토리얼 스킵 UI

## 변경 후 흐름

타이틀 진입 시 입력 대기 없이 기본 타이틀 메뉴를 바로 표시한다. 새 게임 버튼은 스토리 인트로 분기 없이 기존 튜토리얼 여부에 따라 첫 전투 또는 로비로 이동한다. 타이틀 복귀는 별도 스킵 상태를 기록하지 않고 바로 Title 상태로 전환한다.

## 안전 조건

- `TitleIntro` enum 제거 시 나머지 직렬화 값을 명시해 기존 사운드 상태 번호를 보존한다.
- 인트로 로컬라이제이션 키만 제거하고 전투/튜토리얼 키는 유지한다.
- 씬·프리팹은 이름과 계층을 기준으로 인트로 전용 하위 트리만 제거한다.
