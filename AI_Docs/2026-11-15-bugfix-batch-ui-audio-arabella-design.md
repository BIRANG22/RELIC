# UI·BGM·전투 연출 일괄 버그 수정 설계

## 목적

튜토리얼 UI 정렬, BGM 전환과 루프, 월드 HUD 수명주기, 로비 UI 피드백, 몬스터 정보 표시, 아라벨라 및 거미줄 연출에서 보고된 15개 회귀 현상을 수정한다.

## 설계 원칙

- UI와 사운드는 전투 결과를 계산하지 않고 RuntimeId·GridIndex·상태 결과를 표현한다.
- BGM 선택은 `BattleBgmDirector`를 단일 소유자로 유지하고 씬/이어하기 진입도 같은 정책으로 처리한다.
- 월드 HUD와 호버 UI는 대상 RuntimeId와 생존 여부를 확인하고 수명주기를 명시적으로 종료한다.
- 거미줄의 실제 배율 값은 유지하고, 스택처럼 보이는 잘못된 표시만 교정한다.
- 아라벨라 연출은 확정된 방향과 기준 위치를 사용하며 프레젠테이션 단계가 상태를 재계산하지 않는다.

## 변경 단위

### 튜토리얼 UI 계층

튜토리얼 안내 패널이 무조건 마지막 형제가 되는 정책을 제거하고 메뉴 패널이 열려 있을 때 메뉴가 최상위가 되게 한다. 포커스 레이아웃과 툴팁은 명시적인 Canvas 정렬 계층을 사용해 포커스 대상과 설명 UI가 가려지지 않게 한다.

### BGM 진입과 루프

튜토리얼 및 아라벨라 2페이즈 BGM 데이터를 루프로 설정한다. 배틀씬 진입 시 현재 노드와 이어하기 스냅샷을 이용해 `BattleBgmDirector`가 즉시 방 BGM을 선택하게 하여 로비·타이틀 BGM 잔류를 막는다.

### HUD와 호버

사망 유닛 HUD는 사망 결과에서 숨김·언바인드하고 `WorldFollowHUD`가 비활성 대상을 재활성화하지 못하게 한다. 타임라인 몬스터 스킬 호버는 기존 RuntimeId 조회를 재사용해 몬스터 하이라이트와 이름 HUD를 함께 표시한다.

### 로비 및 정보 UI

공명 새로고침 뒤 선택 상태를 즉시 초기화·재계산한다. 연성 패널 물음표는 주변 텍스트와 동일한 TMP 폰트 정책을 사용한다. 몬스터 상태명은 밑줄을 표시하고, 배율형 거미줄은 상태 스택 수치로 출력하지 않는다.

### 아라벨라 및 거미줄 연출

아라벨라 입장 Presenter가 기준 위치와 Idle 진입을 한 번만 복원하도록 하고, 2페이즈 상하 VFX는 매 재생 시 회전을 초기화한 뒤 GridIndex 결과 방향을 적용한다. 거미줄 설치 전 플립은 예약 명령에 확정된 방향을 한 번만 재생한다.

## 검증

- EditMode 테스트로 정책·소스·에셋 계약을 검증한다.
- `Assembly-CSharp.csproj`, `Assembly-CSharp-Editor.csproj`를 빌드한다.
- 씬·프리팹 YAML과 GUID 참조를 검사한다.
- 실제 화면 정렬, 애니메이션 감상, 음원 루프 청취는 에디터 화면 검증이므로 미검증 항목으로 보고한다.

## 멀티플레이 경계

전투 결과와 랜덤 로직은 변경하지 않는다. UI·VFX·BGM은 이미 결정된 RuntimeId, GridIndex, 상태 및 페이즈 이벤트만 소비하므로 동기화 모델에 영향이 없다.
