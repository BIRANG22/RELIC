# 로컬리제이션 선택적 마이그레이션 안전 설계

## 목적

`전체 검사 및 적용` 과정에서 과거 프리팹·씬 구조를 정리하기 위한 일회성 마이그레이션이 현재 프로젝트 구조와 맞지 않더라도 전체 로컬리제이션 동기화가 중단되지 않게 한다.

## 설계

- Excel 변환, 워크북 쓰기, 최종 임포트처럼 데이터 정합성에 직접 영향을 주는 핵심 단계는 실패 시 기존처럼 즉시 중단한다.
- 프리팹·씬 바인딩 보정처럼 재실행 가능한 선택적 단계는 공통 실행기로 격리한다.
- 선택적 단계에서 예외가 발생하면 단계명과 예외를 기록하고 다음 단계로 진행한다.
- 구형 계층 경로 기반 마이그레이션은 대상이 모두 사라졌다면 이미 적용 불가능한 레거시 구조로 판단하고 정상 생략한다.
- 대상 중 일부만 남았다면 부분 변경하지 않고 누락 경로를 경고하여 구조 불일치를 추적할 수 있게 한다.

## 검증

- 대상 경로 전체 부재 시 변경 수 `0` 반환
- 대상 경로 일부 부재 시 부분 변경 없이 `0` 반환
- 선택적 단계 예외 시 후속 실행이 가능하고 실패 결과가 반환됨
- 대상 경로 전체 존재 시 동적 TMP 소유권 설정 유지
- 에디터 어셈블리 컴파일 확인
