# 침식도 점수 표시 및 런타임 로케일 전환 수정 설계

## 문제

- `ErosionSelectPanel/Select/Erosion_Value`가 침식도 선택 점수를 받지 못해 `00`에 고정된다.
- 런타임 로케일 변경 요청이 비동기로 완료될 때 현재 전역 로케일을 다시 간접 조회하여, 연속 전환 중 한국어 원문이 재적용될 수 있다.

## 설계

- `ErosionDifficultyCatalogUI`의 숫자 점수 TMP와 보상 문장 TMP를 별도 직렬화 필드로 분리한다.
- 숫자 TMP에는 `Ready_Panel/Select/Erosion_Value`와 같은 숫자 템플릿 치환 규칙을 사용한다.
- 보상 문장 TMP에는 기존 `lobby.erosion.reward_bonus_format` 키와 계산된 점수를 사용한다.
- 로컬라이저의 비동기 갱신은 이벤트로 전달받은 `Locale`을 조회와 최종 문자열 결정에 모두 명시적으로 사용한다.
- 최신 요청만 적용하는 기존 버전 게이트는 유지한다.

## 검증

- 씬의 숫자/문장 참조가 서로 분리되어 있는지 EditMode 테스트로 확인한다.
- 숫자 템플릿 치환을 순수 함수 테스트로 확인한다.
- 명시적으로 요청한 일본어 로케일에서 누락 키가 한국어 원문이 아닌 `未翻訳`으로 결정되는지 확인한다.
- 런타임 어셈블리와 에디터 테스트 어셈블리를 컴파일한다.

## 멀티플레이 경계

표시용 UI와 로컬라이제이션만 변경하며 침식도 선택 상태, 점수 계산 원본, 전투 결과에는 영향을 주지 않는다.
