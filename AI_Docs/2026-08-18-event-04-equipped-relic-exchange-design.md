# Event_04 장착 유물 등가 교환 설계

## 배경

`Event_04`의 3번 선택지 `등가 교환`은 장착 중인 유물 1개를 선택해 잃고 새로운 무작위 유물 1개를 얻는 이벤트다. 현재 실행 서비스는 `GainRandom / 유물` 보상만 처리하고, 비용으로 지정된 `선택 유물`을 실제 장착 슬롯에서 제거하지 않는다.

`Event_04`의 1번 선택지 `수상한 거래`는 `레드 더스티움 / 파티 / 수량 TBD` 비용을 사용한다. 현재 코드는 `수량 TBD`를 기본 거래 비용 100으로 해석하지만, 회귀 테스트가 없어 선택 가능 조건이 깨져도 드러나기 어렵다.

## 설계

- `선택 유물` 비용은 인벤토리 유물이 아니라 파티 캐릭터의 `EquippedRelicIds`만 대상으로 한다.
- `Event_04` 3번 선택지를 누르면 바로 실행하지 않고, 현재 이벤트 선택 슬롯 UI를 재사용해 삭제할 장착 유물 목록을 보여준다.
- 플레이어가 장착 유물을 고르면 `CharacterId`, `RelicSlotIndex`, `RelicId`를 실행 컨텍스트에 담아 `EventChoiceExecutionService`로 전달한다.
- 실행 서비스는 비용 처리 단계에서 선택된 장착 슬롯을 비운 뒤, 기존 랜덤 유물 보상 큐 흐름을 실행한다.
- 장착 유물 선택 중인 상태는 이벤트룸 내부 UI 상태이며, 실제 전투 상태 변경은 실행 서비스와 런타임 데이터 변경으로만 처리한다.
- `Event_04` 1번은 레드 더스티움 100 미만이면 선택 불가, 100 이상이면 선택 가능 및 비용 소모로 고정한다.

## 검증

- 인벤토리 유물만 있을 때 `등가 교환` 선택 불가 테스트.
- 장착 유물이 있을 때 `등가 교환` 선택 가능 테스트.
- 선택된 장착 유물 비용이 슬롯을 비우고 랜덤 유물 보상을 호출하는 테스트.
- 레드 더스티움 비용 부족/소모 테스트.
- MSBuild와 `git diff --check` 검증.
