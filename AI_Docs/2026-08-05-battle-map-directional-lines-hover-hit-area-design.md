# 배틀 맵 방향별 라인 및 호버 입력 설계

## 목표

- 연결 방향에 맞춰 준비된 3개 라인 스프라이트를 선택하고 노드의 상·하 경계에서 대각선이 보이도록 한다.
- 클릭 가능 여부와 무관하게 모든 지도 노드에서 호버 정보와 아이콘 확대가 동작하도록 한다.

## 라인 표시

- 같은 행은 `line_horizontal`을 사용한다.
- 중간 행에서 위로 연결하면 `line_diagonal_up`을 사용한다.
- 위 행에서 중간 행으로 연결하면 `line_diagonal_up`을 수평 반전한다.
- 중간 행에서 아래로 연결하면 `line_diagonal_down`을 사용한다.
- 아래 행에서 중간 행으로 연결하면 `line_diagonal_down`을 수평 반전한다.
- 라인 RectTransform은 두 노드 중심을 포함하는 축 정렬 영역으로 배치한다. `LineRoot`가 `NodeRoot`보다 뒤에 있으므로 노드 이미지가 중심부 라인을 가리고, 실제 노출 부분은 노드의 중앙·상단·하단 경계에 맞닿는다.
- 라인 이미지는 회전하지 않고, 역방향 표현은 RectTransform의 X 스케일 반전으로 처리한다.

## 호버 입력

- `NodePrefab`에 노드 전체를 덮는 투명 `HoverHitArea`를 마지막 자식으로 둔다.
- `HoverHitArea`의 Image만 레이캐스트를 받고 `MapNodeHoverRelay`가 같은 오브젝트에서 이벤트를 직접 수신한다.
- `MapNodeView`의 Button 활성 여부는 클릭만 제어하고 호버 입력에는 관여하지 않는다.
- `MapViewSpawner`는 릴레이를 자식까지 검색해 노드 데이터, 아이콘, 정보 콜백을 연결한다.
- 호버 확대는 기존과 동일하게 실제 `Icon` 자식만 1.1배 적용한다.

## 검증

- 방향별 스프라이트 분류와 플립 판정을 EditMode 테스트로 검증한다.
- 대각선/수평 RectTransform 배치를 검증한다.
- 자식 호버 릴레이가 진입·종료 콜백을 전달하는지 검증한다.

## 멀티플레이 영향

지도 표시와 포인터 입력 UI만 변경한다. 맵 생성 결과, 노드 선택 상태와 전투 결과에는 영향을 주지 않는다.
