# 몬스터 이동 타임라인 아이콘 회전 설계

## 의도

몬스터 이동 행동이 타임라인에 예약될 때 기본적으로 오른쪽을 향하는 `mon_skill_1` 이동 아이콘을 실제 예약 이동 방향과 일치하도록 회전한다.

## 목표

- `MonsterReservedCommand.MoveOffset`을 기준으로 8방향 회전각을 계산한다.
- 오른쪽을 0도로 두고 기존 이동 경로 UI와 동일한 시계 방향 회전 규칙을 사용한다.
- 이동이 아닌 행동과 방향이 없는 이동은 0도로 표시한다.
- 재사용되는 타임라인 이미지에 이전 행동의 회전이 남지 않게 매 바인딩마다 회전을 덮어쓴다.

## 비목표

- 몬스터 행동 예약, 이동 실행, 방향 전환 판정을 변경하지 않는다.
- 스프라이트 및 프리팹 리소스를 수정하지 않는다.
- `mon_skill_1` 외의 개별 아이콘 ID 분기 구조를 추가하지 않는다.

## 제약

- UI는 예약 결과를 표현하기만 하며 전투 결과를 계산하지 않는다.
- 테스트는 `Assets/Tests/EditMode~/` 아래에 작성한다.
- Unity 에디터 직접 제어 및 batchmode 테스트는 수행하지 않는다.

## 검토한 방식

1. **이동 행동과 `MoveOffset` 기준 회전(채택)**: 데이터 의미를 따르므로 아이콘 ID가 바뀌거나 다른 몬스터 이동 스킬이 추가되어도 동일하게 동작한다.
2. **`mon_skill_1` ID만 회전**: 현재 리소스에는 직접적이지만 문자열 결합도가 높고 새 이동 스킬에서 누락될 수 있어 채택하지 않는다.
3. **프리팹별 방향 아이콘 준비**: 아트 리소스와 DB 항목이 8배로 늘어나며 단일 방향 스프라이트 회전 요구에 비해 과도해 채택하지 않는다.

## 설계

`BattleTimelinePreviewEntry`가 몬스터 이동 명령 여부를 확인하고 `MoveOffset`을 단위 방향으로 정규화해 아이콘 Z 회전각을 제공한다. 각도는 오른쪽 0, 오른쪽 아래 45, 아래 90, 왼쪽 아래 135, 왼쪽 180, 왼쪽 위 225, 위 270, 오른쪽 위 315도다. `BattleTimelineGroupUI`는 스킬 이미지를 바인딩한 직후 이 각도를 적용하며 모든 비이동 항목에는 0도를 적용한다.

## 멀티플레이 경계

기존 예약 명령의 안정적인 결과 데이터인 `MoveOffset`을 읽는 UI 표현 변경뿐이다. Command, State Change, Result/Event 흐름과 동기화 대상에는 영향이 없다.
