# 잃은 체력 피해·속박 이동 차단·유물 순서 설계

## 목표

- `E_MissingHPStrike`는 시전자의 잃은 체력에 효과값 비율을 곱해 기본 피해를 계산한다.
- `E_Bondage`는 일반 이동뿐 아니라 돌진, 후퇴, 도약, 순간이동, 넉백, 그랩 등 GridIndex가 바뀌는 모든 이동을 차단한다.
- 피해 유물은 장착 슬롯 순서대로 적용한다.

## 피해 계산

1. 효과 고유 기본 피해를 확정한다.
   - `E_ArmorStrike`: 현재 방어도 × 효과 계수
   - `E_MissingHPStrike`: `(최대 체력 - 현재 체력) × 효과값 / 100`, 소수점 올림
2. 룬 보정을 적용한다.
3. `EquippedRelicIds`의 낮은 슬롯부터 해당 피해 보정을 하나씩 적용한다.
   - 고정 피해는 즉시 더한다.
   - 비율 피해는 그 시점의 피해에 곱하고 올림한다.
4. 실행 효과와 프리뷰는 확정된 값을 다시 변환하지 않는다.

따라서 방어도 4에서 붉은 서약검(+2) 후 마력 렌즈(+50%)는 9, 반대 순서는 8이다.

## 속박 판정

- 상태 목록을 입력으로 받는 공통 순수 판정/소모 함수를 둔다.
- 이동 실행 직전 판정하고 속박이 있으면 이동을 취소한 뒤 트리거를 1회 소모한다.
- 플레이어 일반 이동 및 방향 이동, 몬스터 일반 이동, 아라벨라 사냥 강습, 넉백과 그랩 경로에 동일한 판정을 적용한다.
- 이동 실패 여부와 관계없이 실제 이동을 시도한 시점에만 소모한다.

## 멀티플레이 경계

- 계산은 RuntimeData와 안정적인 EffectId/슬롯 순서만 사용한다.
- 이동 차단은 상태 변경과 GridIndex 변경 전에 결정한다.
- 애니메이션·VFX는 결과 계산에 관여하지 않는다.
