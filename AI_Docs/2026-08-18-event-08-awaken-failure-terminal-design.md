# Event_08 각성 실패 종료 설계

## 문제

Event_08, Event_08_A, Event_08_B의 각성 선택지가 실패해도 CSV의 `NextEventId`가 그대로 반환되어 다음 선택지로 이어질 수 있다. 또한 이번 이벤트 체인에서 성공으로 얻은 강화 기억을 실패 시 회수하지 않는다.

## 권장 설계

- `Awaken` 결과 선택지가 확률 판정에 실패하면 실행 결과의 `NextEventId`를 비워 이벤트 체인을 즉시 종료한다.
- 이벤트룸 컨트롤러는 기존 완료 흐름대로 선택지를 비활성화하고 진행 버튼만 노출한다.
- Event_08 체인에서 성공한 각성 대상은 `EventChoiceSessionState`에 ID 기반 타깃으로 기록한다.
- 이후 `Awaken` 실패가 발생하면 기록된 타깃 목록을 컨트롤러 콜백으로 전달해 장착 슬롯에서 제거한다.
- 제거는 현재 슬롯이 기록된 강화 기억 ID와 일치할 때만 수행한다. 이미 다른 기억으로 바뀐 슬롯은 건드리지 않는다.

## 멀티플레이 경계

각성 성공/실패 판단과 회수 대상은 캐릭터 ID, 슬롯 종류, 슬롯 인덱스, 스킬 ID로 전달한다. UI 패널은 선택만 담당하고, 실제 상태 변경은 실행 컨텍스트 콜백을 통해 처리한다.
