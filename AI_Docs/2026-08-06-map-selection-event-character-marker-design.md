# 맵 선택 이벤트 캐릭터 마커 설계

## 문제

스타트룸과 휴식룸은 `BattleCharacter`가 없는 `BattleEventWorldPrefab`을 사용하므로 공통 맵 선택 프레젠터가 플레이어 캐릭터를 발견하지 못한다.

## 설계

- 스타트룸·휴식룸에서 파티 캐릭터를 생성할 때 루트에 `BattleMapSelectionCharacterMarker`를 추가한다.
- 공통 프레젠터는 기존 `BattleCharacter`와 새 마커를 모두 수집하되 중복 Transform은 한 번만 처리한다.
- NPC와 장식 오브젝트에는 마커를 붙이지 않아 잘못 이동하지 않도록 한다.
- 마커 캐릭터도 기존 공통 좌표, 오른쪽 바라보기, Collider 비활성 규칙을 그대로 적용받는다.

## 멀티플레이 경계

플레이어 식별용 로컬 연출 마커이며 전투 상태와 네트워크 동기화 데이터에는 영향을 주지 않는다.
