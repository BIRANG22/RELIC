# 누락 번역 즉시 표시 보정 설계

## 목표

- 선택 언어의 번역 항목이 없거나 값이 비어 있으면 한국어 원문을 표시하지 않는다.
- 영어 `Untranslated`, 일본어 `未翻訳`, 중국어 `未翻译`, 스페인어 `Sin traducir` 정책을 화면 활성화 즉시 적용한다.
- 실제 번역 데이터는 이번 작업에서 임의로 추가하지 않는다.

## 조사 결과

- 로비 `Setting/Option/Back2/Name`은 `ui.lobby.text.b1bc1a93`에 연결되어 있지만 영어 테이블에 항목이 없다.
- `LocalizedTMPText.OnEnable`은 비동기 테이블 준비가 끝난 뒤에만 화면을 갱신하므로 그 전까지 씬에 저장된 한국어가 노출될 수 있다.
- `LobbyPositionSharedModalBackground.Awake/OnEnable`이 같은 TMP에 `탐사 거점`을 직접 대입하여, 정상 번역 표시 이후 한국어로 다시 덮어쓴다.
- 배틀 `BattleMapIntroText/IntroText`는 동적 출력이지만 씬과 컴포넌트에 한국어 기본 문구가 남아 있고, 빈 입력 시 이를 직접 사용한다.
- 이벤트 방 진입 인트로는 `EventDefinition.EventName`의 한국어 원본을 직접 반환하여 선택 로케일 정책을 우회한다.
- `GameLocalization`의 최종 누락 번역 정책 자체는 이미 선택 언어별 표준 문구를 반환한다.

## 설계

1. 정적·동적 TMP 로컬라이저는 활성화 또는 원문 갱신 시 현재 선택 언어를 동기적으로 한 번 적용하고, 테이블 준비 후 다시 보정한다.
2. 로비 `Setting/Option/Back2/Name`의 표시 소유자는 `LocalizedTMPText` 하나로 제한하고, 공유 모달 코드의 한국어 직접 대입을 제거한다.
3. `BattleMapIntroText`의 빈 입력은 직렬화된 한국어 문구가 아니라 `battle.intro.enter_battle_area` 키를 조회한다.
4. 이벤트 이름은 `data.event.<eventId>.name` 키로 조회하며, 번역 누락 시 선택 언어의 미번역 문구를 표시한다.
5. 배틀 씬에서 한국어 `message` 직렬화 값을 제거한다.
6. 보고된 정확한 씬 경로와 즉시 갱신 계약을 EditMode 회귀 테스트로 고정한다.

## 구현 계획

1. 실패하는 회귀 테스트를 추가하고 현재 씬/소스가 계약을 위반함을 확인한다.
2. 로컬라이저의 즉시 적용 경로와 배틀 인트로 기본 키 경로를 최소 수정한다.
3. 테스트 소스 컴파일, 런타임/에디터 어셈블리 컴파일, 로컬라이제이션 정적 감사와 diff 검사를 수행한다.
