# 수동 전투 맵 범용 생성 정책 구현 계획

## 목표

기본 배틀의 표준 생성 규칙을 보존하면서 데모를 포함한 작성형 수동 맵이 템플릿별 레이어 수로 생성되게 한다.

## 작업 1: 회귀 테스트

- `Assets/Tests/EditMode~/ManualBattleMapTemplateTests.cs`에 기본 템플릿 0~9 유지 테스트를 정정한다.
- 데모 템플릿의 0~5 경로와 `TryBuildNodes` 성공을 검증하는 테스트를 추가한다.
- 구현 전 테스트 실패를 확인한다.

## 작업 2: 생성 정책 구현

- `ManualBattleMapTemplate`에 생성 정책과 직렬화된 보스 레이어를 추가한다.
- 표준 정책은 기존 랜덤 생성과 제약 검사를 그대로 호출한다.
- 작성형 정책은 작성된 노드를 변형하지 않고 구조 및 인접 연결만 검증한다.
- 연결 생성과 도착 판정에서 템플릿별 보스 레이어를 사용한다.
- 런타임 키에 정책과 보스 레이어를 반영한다.

## 작업 3: 데모 데이터 연결 및 검증

- 데모 템플릿을 작성형 정책으로 지정한다.
- 에디트 모드 테스트, 런타임/에디터 C# 컴파일, diff 검토를 수행한다.
- Unity 에디터가 열려 있으므로 batchmode 테스트는 실행하지 않는다.
- 커밋, Push, PR, 브랜치 및 worktree 작업은 수행하지 않는다.
