# 지도 선택 중 룸 프레젠테이션 설계

- 지도 선택 진입 시 배틀 그리드 효과와 하이라이트를 모두 정리한다.
- 캐릭터는 Z -2의 가로 1열로 이동하고 오른쪽을 바라보며 월드 호버·클릭을 받지 않는다.
- 이벤트룸 종료 시 전환이 화면을 덮은 동안 이벤트룸 대신 직전 배틀룸 배경을 활성화하고 파티 캐릭터만 다시 스폰한다. 이전 배틀 배경이 없으면 현재 이벤트 노드 레이어를 사용한다.
- 지도 선택 종료 시 캐릭터 입력 차단을 복구한다.
- MapPanel 파티 아이콘은 TimelineIcon을 사용한다.
- ExplorationResultPanel은 열릴 때 같은 Canvas의 마지막 형제가 되어 BattleCharacterPanel보다 앞에 표시된다.

전투 RuntimeData의 방향이나 상태는 변경하지 않고 표시 오브젝트만 조정한다.
