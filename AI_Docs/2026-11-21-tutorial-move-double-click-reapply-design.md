# 튜토리얼 이동 버튼 연속 클릭 방어 재적용 설계

## 의도

이동 버튼 안내 직후 사용자가 버튼을 빠르게 연속 클릭해도 이동 선택이 취소되지 않고 다음 그리드 선택 단계를 진행할 수 있게 한다.

## 조사 결과

- 이전 수정의 `allowDeselect` 인자와 패널 호출부 방어가 현재 코드에 없다.
- 관련 회귀 테스트와 이전 설계·계획 문서도 현재 작업 공간에 없다.
- 일반 전투의 `ToggleMoveSkillSelection`은 동일 캐릭터·동일 이동 스킬 재클릭 시 선택과 프리뷰를 취소한다.
- 튜토리얼의 이동 선택 단계가 첫 클릭으로 완료된 직후 두 번째 클릭이 들어오면 이 토글 취소가 실행되고, 다음 단계의 포커스 방어막은 이동 버튼을 막기 때문에 진행이 멈춘다.

## 설계

`BattleTimelineController.ToggleMoveSkillSelection`에 `allowDeselect` 선택 인자를 추가한다. 동일 선택에서 값이 `false`이면 현재 선택을 유지하고 성공을 반환한다. `BattleCharacterPanelUI`는 튜토리얼 표현 중 이동 버튼에만 `allowDeselect: false`를 전달한다. 일반 전투의 기본값은 `true`로 두어 기존 재클릭 취소를 유지한다.

## 비목표

- 튜토리얼 데이터 및 단계 순서 변경
- 이동 예약, 전투 명령, 결과 계산 변경
- 네트워크 동기화 구조 변경

## 검증

실제 `BattleTimelineController` 선택 상태를 사용하는 EditMode 회귀 테스트로 튜토리얼 재클릭 선택 유지와 일반 전투 재클릭 취소를 각각 검증한다. Unity batchmode는 사용하지 않고 테스트 어셈블리 컴파일, 프로젝트 컴파일, 정적 diff 검사를 수행한다.

## 멀티플레이 경계

로컬 입력의 선택·프리뷰 상태만 변경한다. `PlayerReservedCommand`, 슬롯 상태, 안정 ID 기반 동기화 및 전투 결과에는 영향이 없다.
