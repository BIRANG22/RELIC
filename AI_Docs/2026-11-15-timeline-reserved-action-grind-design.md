# 예약 행동 아이콘 갈림 연출 설계

## 목적

예약 행동 실행 후 아이콘이 위로 증발하는 기존 제거 연출을 타임라인 진행 방향인 왼쪽으로 이동하며 기어에 갈려 들어가는 연출로 변경한다.

## 채택 설계

- 기존 확대 후 원래 크기로 돌아오는 선행 연출은 유지한다.
- 제거 구간에는 아이콘을 왼쪽으로 이동시키며 alpha를 0으로 낮춘다.
- 동시에 X 스케일만 인스펙터 설정값까지 축소하고 Y 스케일은 유지하여 가로로 눌려 갈리는 느낌을 만든다.
- 기존 갈림 VFX, 기어 회전, 틱 사운드와 실행 순서는 변경하지 않는다.
- 기존 `moveUpDistance` 직렬화 값은 `FormerlySerializedAs`로 왼쪽 이동 거리 설정에 승계한다.

## 고려한 접근

1. 왼쪽 이동과 페이드만 사용: 변경은 작지만 갈리는 느낌이 약하다.
2. 왼쪽 이동, 가로 압축, 페이드 결합: 기존 구조와 VFX를 재사용하면서 요청한 인상을 강화할 수 있어 채택한다.
3. 별도 파편 VFX 생성: 추가 리소스와 풀링이 필요해 이번 범위를 벗어난다.

## 인스펙터 설정

- `grindMoveDistance`: 아이콘이 왼쪽으로 이동하는 거리
- `grindEndWidthScale`: 종료 시 원래 가로 폭에 대한 비율
- 기존 `fadeOutDuration`, `useUnscaledTime` 사용

## 비목표

- 타임라인 실행 순서 또는 전투 명령 처리 변경
- 타임라인 바 이동 좌표 및 속도 변경
- 신규 VFX 프리팹 또는 사운드 추가

## 멀티플레이 경계

결과 이벤트 이후 재생되는 UI 연출만 변경한다. Command, State Change, Result/Event 및 네트워크 스냅샷에는 영향이 없다.
