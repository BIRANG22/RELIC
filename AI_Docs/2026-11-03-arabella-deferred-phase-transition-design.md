# 아라벨라 지연 페이즈 전환 설계

## 의도

아라벨라 1페이즈가 턴 도중 HP 0이 되더라도 턴 전체를 중단하지 않는다. 해당 아라벨라의 남은 예약만 제거하고 다른 전투 개체의 행동은 계속 실행한 뒤, 타임라인 행동 종료 시 2페이즈 전환 연출을 재생한다.

## 실행 흐름

`1페이즈 HP 0 -> 전환 예약 -> 1페이즈 사망 대기 표현 -> 동일 RuntimeId의 남은 명령 제거 -> 다른 행동 계속 -> 타임라인 행동 종료 -> 카메라 줌인 -> 2페이즈 상태 교체/연출 -> 카메라 복귀 -> 턴 종료 처리`

- 현재 실행 중인 슬롯의 행동과 UI 순서는 그대로 유지한다.
- 사망한 슬롯보다 뒤 슬롯에서 아라벨라의 `RuntimeId`와 일치하는 몬스터 명령만 제거한다.
- 플레이어와 다른 몬스터의 예약은 유지한다.
- 2페이즈 행동은 현재 턴에 추가하지 않고 다음 턴 예약 단계에서 즉시 생성한다.
- 페이즈 전환은 타임라인 행동이 끝난 뒤, 일반 턴 종료 효과 전에 완료한다.

## 표현

- 아라벨라 Animator Controller에 `PhaseOneDefeated` 상태를 추가한다.
- 임시 Motion은 반복 가능한 `Idle` 클립을 연결하며 아트 작업자가 나중에 교체할 수 있다.
- 1페이즈 사망 시 일반 `PlayDead`, 디졸브, 보상, 오브젝트 제거는 실행하지 않는다.
- 턴 행동 종료 시 기존 `CompletePendingTransitionRoutine`의 카메라 줌, 2페이즈 애니메이션/VFX, 카메라 복귀를 사용한다.

## 고려한 접근

- 선택: `RuntimeId` 기준으로 타임라인 원본과 미실행 배치에서 명령을 제거한다. 페이즈 전환 전후에도 동일한 전투 개체를 안정적으로 식별한다.
- 제외: `MonsterId`가 `Mon_12_1`인 명령을 실행 시점에만 무시한다. UI 데이터에 예약이 남고 실행 상태와 표시가 달라진다.
- 제외: 전역 Skip 상태를 대상 지정형으로 확장한다. 전역 mutable 상태가 복잡해지고 다른 행동을 다시 막을 위험이 있다.

## 검증

- 동일 RuntimeId의 남은 몬스터 명령만 제거되는지 검증한다.
- 플레이어 및 다른 몬스터 명령이 유지되는지 검증한다.
- 페이즈 전환 예약 시 1페이즈 사망 대기 표현 정책이 선택되는지 검증한다.
- 프리팹과 Animator Controller에 `PhaseOneDefeated` 상태 및 임시 반복 Motion이 연결되는지 YAML로 검증한다.
- 런타임 및 에디터 어셈블리 컴파일을 검증한다.

## 멀티플레이 영향

명령 제거 대상은 Scene Object가 아니라 기존 `RuntimeId`로 결정한다. 페이즈 전환 State Change와 표현은 분리하고 랜덤이나 네트워크 프레임워크를 추가하지 않는다.
