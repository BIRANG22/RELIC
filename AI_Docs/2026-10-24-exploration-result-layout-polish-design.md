# 탐사 정산 패널 정렬 및 빈 슬롯 개선

## 조사 결과

- 소요시간은 `ExplorationReportStageTime` 하나에 라벨과 값을 함께 출력하고 있어 좌우 정렬을 따로 지정할 수 없다.
- 캐릭터 보유 유물·스킬 슬롯은 데이터가 없는 슬롯을 비활성화하므로 빈 슬롯 배경도 사라진다.
- 세 캐릭터 경험치 게이지의 현재 크기는 모두 `250 x 24`이다.

## 승인된 설계

- 소요시간을 `ExplorationReportElapsedTimeLabel`과 `ExplorationReportElapsedTimeCount`로 분리한다.
- 라벨은 일반 전투 라벨과 같은 `207 x 56`, 글자 크기 30, 왼쪽 정렬을 사용한다.
- 값은 같은 높이와 Y축에 배치하고 글자 크기 42, 오른쪽 정렬을 사용한다.
- 캐릭터별 유물 6칸과 기억 4칸은 항상 활성화하고, 값이 없으면 슬롯의 빈 상태를 표시한다.
- 유물은 배율 `0.36`, 가로 간격 `40`, 열 수 `6`으로 설정해 반드시 한 줄에 배치한다.
- 기억은 배율 `0.52`, 가로 간격 `60`, 열 수 `4`로 설정해 반드시 한 줄에 배치한다.
- 소요시간 행은 전투 횟수 행과 동일한 `ExplorationReportStageGroup`을 사용한다.
- 소요시간 라벨은 일반전투 라벨과 동일한 왼쪽 기준선을 사용하고, 시간 값은 전투 횟수 값과 동일한 오른쪽 기준선을 사용한다.
- 세 경험치 게이지를 `220 x 32`로 통일한다.

## 검증 계획

- EditMode 회귀 테스트로 씬 오브젝트의 정렬·크기와 빈 슬롯 바인딩 규칙을 검사한다.
- `Assembly-CSharp`와 `Assembly-CSharp-Editor`를 컴파일해 런타임 및 테스트 코드 오류를 확인한다.
- Unity 에디터에서 실제 패널의 해상도별 시각 확인은 수동 검증 항목으로 남긴다.
