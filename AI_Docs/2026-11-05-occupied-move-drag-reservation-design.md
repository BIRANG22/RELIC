# 점유 칸 드래그 이동 예약 설계

## 목표

드래그로 명시한 이동 경로에서는 캐릭터와 몬스터의 현재·예상 점유 칸도 예약할 수 있게 한다.

## 규칙

- 드래그 경로의 중간 칸과 도착 칸에 있는 플레이어 및 몬스터 점유는 예약을 막지 않는다.
- 다른 플레이어가 도착할 예정인 칸도 드래그 경로로 예약할 수 있다.
- 이동 불가 그리드 효과도 드래그 경로 예약을 막지 않고 실행 시 판정한다.
- 맵 경계, 예약 가능 거리와 코스트 제한은 유지한다.
- 일반 클릭 이동의 자동 경로 선택 규칙은 변경하지 않는다.
- 실행 시 충돌과 후속 경로 처리는 예약 이동 경로 우선 실행 규칙을 따른다.

## 구조

드래그 예약 정책은 유닛 점유와 이동 불가 그리드 효과를 모두 실행 단계 판정으로 넘긴다. 명시 경로가 있는 예약 확정에서는 점유 도착 칸 조기 거부를 생략한다.
