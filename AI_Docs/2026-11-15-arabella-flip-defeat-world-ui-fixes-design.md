# 아라벨라·플립·탐사 종료 월드 UI 수정 설계

## 목적

아라벨라 최초 등장 대사 중 사라진 카메라 줌인·줌아웃을 복원하고, 다음 행동과 결합되지 않은 플립을 다른 캐릭터 선택 시 취소하며, 탐사 종료 화면 위에 전투 월드 HUD와 피해·효과 팝업이 남지 않게 한다.

## 조사 결과

- 아라벨라 프리팹의 첫 카메라 단계가 `CameraMove(0)`에서 `CameraHold(10)`로 변경되어 카메라 시네마틱 소유권을 얻지 못한다. 따라서 목표 좌표로 이동하지 않고 종료 복귀도 실행되지 않는다.
- 미결합 플립 제거 API인 `CancelUnmergedFacingFlips()`는 슬롯 변경과 턴 종료에는 연결되어 있지만 `SelectCharacter()`의 실제 캐릭터 교체에는 연결되어 있지 않다.
- `BattleResultChecker.PrepareBattleFinishedPresentation()`은 애니메이션과 전투 UI만 복구한다. `BattleDamageTextPopupUI`의 대기열·코루틴·생성 팝업과 몬스터 임시 HUD를 종료 시점에 정리하지 않는다.

## 접근 방식

### 선택한 방식: 기존 소유자에 최소 복구 경계 추가

- 아라벨라 프리팹의 첫 단계만 `CameraMove`로 복원한다. 기존 `BossSpawnPresentation`의 캡처·블렌드·복귀 로직을 그대로 사용한다.
- 아라벨라 등장 종료 시에는 원위치 복귀 블렌드를 생략하고 현재 줌 자세에서 시네마틱 소유권만 해제한다. 이후 선택 캐릭터 카메라가 현재 자세를 시작점으로 이어받는다. 다른 보스는 기존 복귀 동작을 유지하도록 인스펙터 옵션으로 제어한다.
- `BattleTimelineController.SelectCharacter()`에서 CharacterId가 실제로 달라질 때만 미결합 플립을 취소한다. 다음 행동에 이미 병합된 `FlipBeforeAction`은 보존한다.
- `BattleDamageTextPopupUI`에 전투 종료 전용 정적 정리 API를 추가한다. 진행 코루틴, 회복/방어 대기열, 생성된 팝업을 제거하고 전투 캔버스로 복귀 가능한 초기 상태로 만든다.
- 전투 종료 공통 준비 지점에서 팝업 정리, 캐릭터 HUD 숨김, `MonsterUnit.HideAllTemporaryHUDs()`를 호출한다.

### 제외한 방식

- 결과 패널 Canvas의 sorting order로 덮는 방식은 화면에서만 숨길 뿐 대기열과 임시 HUD 상태가 남으므로 제외한다.
- 모든 플립 예약을 캐릭터 교체 시 제거하는 방식은 이미 행동에 결합된 확정 명령까지 훼손하므로 제외한다.
- 새 카메라 코드를 추가하는 방식은 기존 `BossSpawnPresentation` 흐름과 중복되므로 제외한다.

## 검증

- EditMode 소스·에셋 계약 테스트로 첫 카메라 단계, 캐릭터 변경 취소 경계, 전투 종료 정리 호출을 고정한다.
- `Assembly-CSharp.csproj`와 `Assembly-CSharp-Editor.csproj`를 빌드한다.
- `git diff --check`와 변경 범위를 확인한다.
- Unity 에디터 화면에서 실제 줌과 팝업 소멸을 감상하는 검증은 수행하지 않는다.

## 멀티플레이 영향

전투 결과와 랜덤, 네트워크 명령 형식은 변경하지 않는다. 미결합 플립은 기존 예약 상태 변경 API로 제거하며, 카메라와 HUD 정리는 로컬 표현 계층에만 영향을 준다.

## 아라벨라 턴 시작 거미줄 카메라 동기화

아라벨라의 턴 시작 거미줄 행동은 대상과 설치 후보를 기존 `BattleRandom`으로 결정한 뒤, 행동 애니메이션을 시작하기 전에 현재 전투 카메라 이동 완료를 기다린다. 카메라 이동이 없거나 카메라 컨트롤러가 없으면 즉시 기존 흐름을 진행한다. 다른 몬스터 특성과 일반 행동 카메라는 변경하지 않는다.
