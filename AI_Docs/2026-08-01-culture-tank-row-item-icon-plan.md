# 배양조 행 아이템 아이콘 구현 계획

1. 행 아이콘 상태 해석에 대한 EditMode 회귀 테스트를 추가한다.
2. `TankRow`에 `ItemIcon` 바인딩 및 필요 시 생성 로직을 추가한다.
3. 행 갱신 시 빈 상태, 연구 중, 완료 상태별 스프라이트를 적용한다.
4. C# 프로젝트 빌드와 변경 파일 검사를 수행한다.
5. Unity Test Runner는 열려 있는 에디터에서 사용자가 실행할 수 있도록 검증 미수행 항목에 기록한다.
6. 비활성 배양조에서 완료 피드백 코루틴을 시작하지 않는 회귀 테스트와 방어 처리를 추가한다.
