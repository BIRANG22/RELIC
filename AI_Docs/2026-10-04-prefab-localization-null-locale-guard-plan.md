# 프리팹 편집 시 Localization null 로케일 오류 방지 구현 계획

1. 편집기 프리뷰 차단과 null locale fallback을 요구하는 회귀 테스트를 먼저 추가한다.
2. 런타임 TMP 자동 처리 정책에 Play Mode 경계를 추가한다.
3. 런타임 누락 감지기도 같은 Play Mode 경계를 적용한다.
4. 공용 문자열 조회와 정적·동적 비동기 갱신에서 null locale 데이터베이스 요청을 차단한다.
5. 계약 검증과 런타임/에디터 어셈블리 컴파일을 수행한다.
6. 프로젝트 규칙에 따라 batchmode 테스트는 실행하지 않는다.
