# 배틀룸 이동 전환 Walk 애니메이션 교체 설계

## 목적

- 배틀씬의 노드 입장, 노드 퇴장, 지도 선택 캐릭터 이동에서 기존 `Move` 애니메이션과 이동 VFX를 사용하지 않는다.
- 해당 표현 경로에서는 각 캐릭터 전투 Animator Controller의 `walk` 상태만 재생한다.
- 실제 전투 중 그리드 이동은 기존 `Move + VFX` 동작을 유지한다.

## 설계

- `BattleUnitAnimator`에 VFX를 생성하지 않는 표현 전용 `PlayWalk()`를 추가한다.
- `BattleRoomPartyTransitionPresenter`는 전환 이동에서 `PlayMove()` 대신 `PlayWalk()`를 호출한다.
- 지도/이벤트/휴식/시작 노드 캐릭터용 `BattleMapSelectionCharacterMarker`도 전투 Controller의 `walk` 상태를 재생하고, 전환 종료 시 원래 Controller와 Idle을 복원한다.
- 전환 전용으로 추가됐던 다른 프리팹의 Move VFX 복제 API와 관련 테스트는 제거한다.
- 전투 명령 처리에서 사용하는 `PlayMove()`와 `moveVfx` 설정은 변경하지 않는다.

## 검증

- 전환 Marker가 전투 Controller의 `walk` 상태를 재생하는지 확인한다.
- `BattleUnitAnimator.PlayWalk()` 호출 시 Move VFX가 생성되지 않는지 확인한다.
- 실제 전투용 `PlayMove()`가 기존 VFX 호출을 유지하는지 코드와 컴파일로 확인한다.
- 관련 EditMode 테스트와 스크립트 컴파일을 검증한다.

## 멀티플레이 영향

- 위치 보간 중 재생하는 로컬 표현만 교체한다. 전투 Command, 상태 변경, 결과 이벤트, Runtime ID 및 네트워크 동기화 데이터에는 영향이 없다.

## 이동 속도 조정

- 배틀 씬의 진입·퇴장 시간과 보간 커브는 유지한다.
- 진입·퇴장 오프셋을 기존 `-8 / +8`에서 정확히 1/3인 `-2.6666667 / +2.6666667`로 줄인다.
- 같은 시간 동안 이동하는 거리가 1/3이 되므로 체감 이동 속도도 약 1/3이 된다.
- 캐릭터는 맵 바깥 먼 위치 대신 최종 위치와 가까운 지점에서 생성되어 걷기 시작한다.

## 입장 중 캐릭터 HUD 표시

- 캐릭터 월드 HUD는 입장 시작과 동시에 모두 비활성화해 반투명 캐릭터 위에 먼저 노출되지 않게 한다.
- 몬스터 HUD는 캐릭터 Runtime 바인딩 여부로 구분하여 이 처리에서 제외한다.
- 워크 전환과 초기 예약 연출이 끝난 뒤 최초 캐릭터 선택 상태를 먼저 반영하고 캐릭터 HUD를 다시 활성화한다.
- 선택된 캐릭터 HUD만 기존 선택 표시 규칙에 따라 보이고 나머지는 숨김 상태를 유지한다.
