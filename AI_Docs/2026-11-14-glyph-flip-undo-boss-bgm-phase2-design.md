# 글리프·플립 Undo·보스 BGM·2페이즈 BGM 설계

## 목적

- DungGeunMo 폰트의 `?`가 ㅂ처럼 보이는 문제를 모든 사용 에셋에서 제거한다.
- 행동 Undo 후 단독으로 남은 플립 예약을 자동 취소한다.
- 보스방 이어하기에서 일반 전투 BGM이 보스 BGM을 덮어쓰지 않게 한다.
- 아라벨라 2페이즈 연출 시작에 기존 BGM을 페이드아웃하고 연출 완료 후 2페이즈 BGM을 페이드인한다.

## 설계

### 물음표 글리프

- `DungGeunMo SDF`와 `DungGeunMo Legacy SDF`의 잘못된 U+003F 직접 매핑을 제거한다.
- 두 폰트에 정상 물음표를 가진 `LiberationSans SDF`를 fallback으로 연결한다.
- 의도적인 `???` 문자열은 의미를 유지하고 렌더링 글리프만 교체한다.

### 플립 Undo

- 성공한 Undo 뒤에 `IsFacingFlipCommand`로 남은 미병합 플립을 내부 정리한다.
- 행동 제거·이동 Undo 모두 동일한 후처리를 사용한다.
- 히스토리 알림, 시뮬레이션, 타임라인, HUD, 고스트 갱신은 중복 호출하지 않는다.

### 보스방 이어하기

- 전투 씬 로드 뒤 미완료 현재 노드가 있으면 `BattleState`의 기본 `Stage1Common` 재생을 생략한다.
- 방이 없는 새 전투 맵 진입에서만 기본 일반 BGM을 재생한다.
- 실제 방별 BGM 결정은 계속 `BattleBgmDirector`가 소유한다.

### 아라벨라 2페이즈 BGM

- 페이즈 데이터 적용 이벤트와 별도로 연출 시작·완료 이벤트를 둔다.
- 실제 전환 코루틴이 시작될 때 기존 BGM만 지정 시간 동안 페이드아웃한 뒤 정지한다.
- 애니메이션, HUD 종료, 카메라 복귀가 끝난 뒤 2페이즈 BGM을 지정 시간 동안 페이드인한다.
- 페이드아웃·페이드인 시간은 `BattleBgmDirector` 직렬화 필드로 노출한다.
- `AudioManager`는 일반 크로스페이드 기본값을 보존하면서 호출별 fade 시간과 BGM 단독 fade-out을 지원한다.

## 비범위

- 플립 판정과 실행 결과는 변경하지 않는다.
- 저장 데이터 형식은 변경하지 않는다.
- 아라벨라 전투 상태 적용 시점은 변경하지 않는다.
