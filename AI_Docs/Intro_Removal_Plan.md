# Intro Removal Implementation Plan

**Goal:** 사용하지 않는 스토리 인트로와 Press Any Key 흐름 및 전용 자산을 완전히 제거한다.

**Architecture:** 타이틀 시작 흐름을 직접 메뉴 진입으로 단순화하고, 전투 인트로 경계는 그대로 유지한다. 코드·씬·프리팹·로컬라이제이션·리소스의 역참조가 남지 않도록 회귀 검사한다.

**Spec:** `AI_Docs/Intro_Removal_Design.md`

## Tasks

1. 제거/보존 경계 회귀 테스트를 먼저 추가하고 실패를 확인한다.
2. 시작·복귀·옵션·설정 코드에서 인트로 분기를 제거한다.
3. Bootstrap 씬과 Option 프리팹의 인트로 전용 계층을 제거한다.
4. 전용 코드·아트·로컬라이제이션·사운드 상태를 제거한다.
5. 잔존 참조, C# 컴파일, 데이터 정합성을 검증한다.
