# 런타임 한국어 하드코딩 감사

## 범위

- 플레이어 화면에 직접 출력되는 C# 한국어 문자열을 조사한다.
- 주석, Inspector 설명, Editor 도구, Debug 로그, 데이터 입력 호환용 판별 문자열은 번역 대상에서 제외한다.
- 이미 `GameLocalization.Get`의 키를 사용하고 한국어를 편집기용 원문 또는 fallback으로 전달하는 경로도 직접 출력 하드코딩과 구분한다.

## 이번 수정

- 기록서 미발견 슬롯 이름을 `ui.record.undiscovered` 키로 교체했다.
- 한국어, 영어, 일본어, 중국어 간체, 스페인어 테이블에 미발견 번역을 연결했다.
- 유물 사용 불가 경고 두 곳을 기존 `warning.relic.unavailable_now` 키로 교체했다.
- 로비 스킬 강화 실패 경고를 기존 통화 부족 및 기능 사용 불가 키로 교체했다.
- 전투 스킬 상세의 효과 설명 없음 문구를 기존 `common.no_effect_description` 키로 교체했다.

## 별도 데이터 현지화 영역

- 이벤트 내러티브와 이벤트 결과 문장은 다수의 기존 `event.*` 키와 데이터 판별 문자열이 혼재한다.
- 탐사 결과 보고서는 여러 수치와 목록을 조합하는 복합 포맷 문장이다.
- 이 두 영역은 단순 문자열 치환 시 포맷 인자나 이벤트 데이터 판정에 영향을 줄 수 있으므로 전용 포맷 키 단위로 다뤄야 한다.

## 재발 방지

- 기록서 미발견 이름이 `LocalizationKeys.Record.Undiscovered`를 사용하고 소스에 한국어 리터럴을 남기지 않는 EditMode 회귀 검사를 추가했다.
