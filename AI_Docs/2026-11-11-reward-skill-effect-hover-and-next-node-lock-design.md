# 스킬 획득 효과 호버 및 다음 노드 선택 잠금 설계

## 목표

- 스킬 획득 패널의 세 후보 카드에 마우스를 올리면 전투 스킬 툴팁과 동일한 효과 설명 목록을 표시한다.
- 다음 노드 깃발 하나를 선택한 직후 다른 깃발의 호버와 클릭을 모두 차단한다.

## 스킬 효과 호버

- `BattleRewardSkillPanelUI`의 후보 카드 hover 상태를 이용한다.
- 후보 스킬의 `EffectEntries`를 필요 시 파싱하고, 중복 효과 ID를 제거한 뒤 기존 `UnitStatusEffectTooltipUI.ShowSkillEffectList`로 표시한다.
- 카드 자체를 anchor로 사용하며 카드 이탈, 선택 시작, 패널 비활성화 시 즉시 숨긴다.
- 장착 슬롯용 기존 상세 툴팁은 변경하지 않는다.

## 다음 노드 잠금

- `BattleNextNodeSelectionPanel`이 입력 잠금 상태와 루트 `CanvasGroup`을 소유한다.
- `BattleMapPanel.OnNextNodeSelected`에서 권한 및 기본 조건을 통과한 첫 선택만 접수하고 즉시 패널 전체 raycast를 차단한다.
- 잠금 시 다른 선택지 hover와 지도 하이라이트를 해제하고, 선택된 깃발의 선택 연출은 유지한다.
- 다음 `Open()`에서 잠금을 해제한다.
- 공유 전투 상태를 수정할 권한이 없는 클라이언트는 잠금 및 선택을 시작하지 않는다.

## 비목표

- 스킬 카드의 기존 설명/레이아웃을 재설계하지 않는다.
- 노드 선택 결과나 네트워크 포맷을 변경하지 않는다.
