# Event_08 장착 기억 각성 패널 설계

## 배경

Event_08의 `Awaken / 선택 기억` 결과는 선택 대상 UI가 필요한 데이터지만, 현재 EventRoom에는 기억 선택 패널이 배치되어 있지 않다. 또한 `미각성 기억 1개 이상` 조건이 실제 강화 가능한 장착 기억이 아니라 단순 기억 보유 여부로 판정된다.

## 목표

- EventRoom에 씬 배치 기반 기억 각성 패널을 추가한다.
- 패널은 현재 파티 캐릭터가 장착 중인 기억 중 강화되지 않았고 강화 대상 ID가 존재하는 기억만 보여준다.
- 선택한 기억은 Event_08 확률 판정 성공 시 해당 장착 슬롯에서 강화판 기억 ID로 교체한다.
- 인벤토리 기억은 Event_08 후보에서 제외한다.

## 구조

- `EventChoiceExecutionService`
  - 선택 기억 대상을 표현하는 값 타입을 추가한다.
  - `Awaken / 선택 기억` 결과는 선택 대상이 있으면 실행 가능하도록 한다.
  - `미각성 기억` 조건은 강화 가능한 장착 기억 존재 여부로 판정한다.
- `EventRoomController`
  - 장착 기억 후보를 수집한다.
  - 선택지 클릭 시 Event_08 각성 패널을 열고, 선택 결과를 EventChoice 실행 컨텍스트에 전달한다.
  - 상태 변경은 캐릭터 ID와 슬롯 타입/인덱스로 적용하고 UI는 결과 후 갱신한다.
- `EventSkillAwakenSelectionPanelUI`
  - 씬에 배치된 루트, 콘텐츠 루트, 옵션 템플릿을 사용한다.
  - 옵션 선택 콜백만 전달받고 직접 전투 상태를 변경하지 않는다.

## 멀티플레이 경계

Event_08의 실제 상태 변경은 UI가 아니라 EventRoom 실행 흐름에서 캐릭터 ID와 슬롯 정보를 통해 수행한다. 확률 판정은 기존 EventChoiceExecutionService 흐름과 `BattleRandom` 경로를 유지한다.
