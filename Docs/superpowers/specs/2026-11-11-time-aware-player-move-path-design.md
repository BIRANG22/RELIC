# 시간 기반 아군 이동 충돌 회피 설계

## 의도

그리드 목적지를 클릭해 이동을 예약할 때, 같은 슬롯에서 먼저 예약된 아군의 이동과 충돌하지 않는 최단 경로를 자동 선택한다. 앞 캐릭터가 이미 빠져나간 칸은 뒤 캐릭터가 지나갈 수 있어야 한다.

## 목표

- 기존 벽, 몬스터, 그리드 효과, 이동 비용 조건을 유지한다.
- 먼저 실행되는 플레이어 이동을 스텝별 위치 변화로 재생한다.
- 동일 시점에 두 캐릭터가 같은 칸을 점유하는 경로를 제외한다.
- 동일 시점에 두 캐릭터가 서로의 칸을 맞바꾸는 교차 이동을 제외한다.
- 충돌하지 않는 후보 중 이동 스텝 수가 가장 짧은 경로를 선택한다.
- 앞 캐릭터가 빠져나간 칸을 이후 시점에는 다시 사용할 수 있다.

## 범위 밖

- 사용자가 드래그로 직접 지정한 이동 경로를 자동 수정하지 않는다.
- 몬스터 행동 순서나 Swift/일반 행동 정렬 규칙을 바꾸지 않는다.
- 대기 행동을 새로 만들지 않는다. 이동만으로 도달할 수 없다면 해당 목적지는 선택 불가로 유지한다.

## 선택한 접근

시간 확장 BFS를 사용한다. 탐색 상태는 `(그리드 칸, 이동 스텝 시점)`이며, 기존 정적 장애물 검사에 먼저 예약된 아군의 시점별 점유 및 이동 간선 충돌 검사를 추가한다. 기존 최단 경로를 만든 뒤 보정하는 방식은 복잡한 우회 경로를 놓칠 수 있어 사용하지 않는다.

## 데이터 흐름

1. 현재 슬롯의 플레이어 명령을 실제 실행 순서로 읽는다.
2. 새 이동보다 앞선 다른 캐릭터의 이동 명령을 상대 이동 스텝으로 재생한다.
3. 각 시점의 `이전 칸 → 다음 칸` 예약표를 만든다.
4. 클릭 목적지에 대해 시간 확장 BFS를 실행한다.
5. 후보 이동이 같은 시점의 점유 칸 또는 반대 방향 간선과 충돌하면 제외한다.
6. 선택된 경로를 기존 이동 명령 분할 및 비용 계산 로직으로 예약한다.

## 검증

- 앞 캐릭터가 한 칸 비운 뒤 뒤 캐릭터가 그 칸을 따라가는 경우 허용.
- 같은 시점에 같은 칸으로 진입하는 경우 우회.
- 서로 자리를 맞바꾸는 경우 우회.
- 충돌 없는 기존 최단 경로는 그대로 선택.
- 우회 경로가 이동 예약 용량을 초과하면 목적지 선택 불가.
- 직접 드래그한 경로는 기존 동작 유지.
